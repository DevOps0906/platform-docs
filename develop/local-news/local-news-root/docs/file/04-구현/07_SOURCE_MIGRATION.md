# 07 원본 이식과 폐기: 로컬뉴스 클라우드(가칭)

작성일 2026-10-15. 이 제품은 원본 프로젝트가 없는 신규 기획이다(README 3장). 그래서 이 장은 (1) 이식할 원본 코드는 없고 (2) 고객 신문사가 쓰던 기존 CMS의 **데이터 이관** 계획(NW-F-063, NW-06-018)과 (3) 벤치마크에서 보았지만 일부러 가져오지 않는 패턴을 적는다.

## 1. 원본별 자산 분류

| 자산 | 상태 | 처리 | 대상 위치 | 근거 |

## 2. 이식 자산 상세 (기존 CMS → 로컬뉴스 클라우드)

| 단계 | 할 일 | 규칙 |
|---|---|---|
| 1 원천 확인 | 기존 사이트의 내보내기 수단을 확인: RSS(최근 N건), XML·CSV 내보내기(벤더 제공 여부 미확인), 사이트맵 + 기사 페이지 수집(고객 소유 사이트, 고객 서면 동의) | 고객이 저작권자임을 확인하는 이관 동의서(제안). 통신사 전재 기사는 이관하지 않는다(재전재 권리 없음) |
| 2 필드 매핑 | 제목·부제·본문·작성일·수정일·기자·섹션·사진·캡션·원 URL → `title`, `subtitle`, `body`(블록으로 변환), `first_published_at`, `revised_at`, `byline`, `section_id`, `hero_media_id`, `legacy_url` | 기사 유형은 기본 `original`, 원문에 "보도자료"·"제공" 표기가 있으면 `press_release` 후보로 표시하고 편집국이 확인(자체기사 비율 왜곡 방지, 05장 위험 #9) |
| 3 중복 방지 | `legacy_id`(원 시스템 기사 번호) 또는 원 URL 해시로 같은 신문사 안 유일 | 재실행해도 중복 0(NW-06-018 수용 기준) |
| 4 사진 | 원본을 받아 재업로드, 파생본 생성, `alt_text`가 없으면 캡션 또는 "이관 사진"으로 채우고 검토 목록에 올림, 출처(`credit`)는 원문 표기 유지 | 외부 핫링크 금지 |
| 5 기자 | 바이라인 문자열을 `news.staff`와 이름으로 매칭, 없으면 바이라인 문자열만 저장 | 계정을 자동 생성하지 않는다 |
| 6 리디렉션 | 원 URL → 새 기사 URL 301 맵 생성. 원 도메인을 그대로 커스텀 도메인으로 연결하면 같은 경로 규칙으로 301 | 검색 순위 유지(02장 6절 위험) |
| 7 검증 | 원천 건수와 이관 건수, 실패 행 보고서, 표본 20건 사람 확인 | Standard 이상 1회 무료(D-10), 이후 유료(제안) |
| 8 전환 | 도메인 전환 → 사이트맵 제출 → 포털(네이버 서치어드바이저 등) 사이트 이전 신고(절차 미확인) | 운영 SOP(NW-06-056) |

## 3. 폐기 목록과 사유

분석 문서의 "폐기" 항목은 없다(신규 제품). 대신 벤치마크에서 관찰했지만 일부러 가져오지 않는 패턴을 적는다(근거: `docs/reference/research/DESIGN_BENCHMARK.md` 0·4장).

| 패턴 | 관찰 위치 | 가져오지 않는 이유 | 대신 |
|---|---|---|---|
| 팝업·전면광고·카운트다운 인터스티셜 | 한라일보, 옥천신문(https://www.ihalla.com, http://www.okinews.com/) | Better Ads 기준 미달, Google 검색 불이익, 고령 독자 이탈 | 팝업 컴포넌트 자체를 제공하지 않음, 하단 고정 배너 |
| 기관·지자체 배너 여러 줄 | 경인일보 중단(https://www.kyeongin.com) | 광고 밀도·신뢰 저하 | 지자체 공고 텍스트 리스트(NW-F-034), 배너 수 상한 |
| CMS 벤더 로고 강제 노출 | 엔디소프트 사이트 푸터(https://www.yongin21.co.kr) | 신문사 브랜드 훼손 | "Powered by" 표기는 L2부터 숨김 가능(`Multi-tenant_Theming` MT-D3) |
| 낚시성·선정 배너 | 기자협회보 보도(https://www.journalist.or.kr/m/m_article.html?no=47102) | 신뢰·포털 감점 | 소재 검수(NW-06-025), 카테고리 차단 |
| 광고 없을 때 슬롯 접기 | web.dev CLS 가이드(https://web.dev/articles/optimize-cls) | 레이아웃 이동(CLS) | 공간 예약 + 하우스 광고 |
| 청소년보호책임자 이름 없이 링크만 | 경인일보 푸터 | 신문법 시행령상 첫 화면 성명 표시 의무(01장 6절) | 법정 푸터 필수 필드(NW-06-022) |
| 비공개 요금·데이터 반출 불명 | 엔디소프트(요금 비공개, 미확인) | 고객 전환 장벽이자 신뢰 문제 | 공개 가격(01장 4절), 해지 시 전체 내보내기(NW-F-064) |

## 5. 아카이브 절차

| 단계 | 작업 |
|---|---|
| 1 | 고객 신문사의 기존 사이트는 이관 검증(2절 7단계) 전까지 그대로 둔다(읽기 전용 권장) |
| 2 | 전환 직전 기존 사이트 전체 백업(고객 보관), 사진 원본 보관 |
| 3 | 도메인 전환 후 301 맵 동작을 표본 100건으로 확인, 30일간 404 로그 감시 |
| 4 | 기존 CMS의 관리자 계정·API 키는 고객이 폐기. 플랫폼은 이관에 쓴 임시 자격증명을 이관 직후 삭제(감사 1행) |
| 5 | 이관 원천 파일(CSV·XML)은 이관 완료 후 30일 보관 후 삭제(제안) |
