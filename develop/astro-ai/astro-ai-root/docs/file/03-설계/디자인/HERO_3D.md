# 3D 히어로 표준 (전 제품 공통)

작성일 2026-10-13. 확정 결정 15의 정본이다. 모든 제품의 메인페이지(랜딩) 히어로는 이 표준을 따른다. 각 제품 `03_SCREENS_UX.md` 4절은 3D 소재와 장면 연출만 정하고, 기기 구성·대체 화면·성능 예산은 이 문서를 인용한다. `DESIGN_PRINCIPLES.md` 절차(레퍼런스, 브리프, 토큰 플랜, 기본값 회피 검토)는 그대로 적용한다.

## 1. 기기별 구성

| 기기 | 기준 폭(제안) | 구성 |
|---|---|---|
| PC | 1280px 이상 | 풀 3D 히어로. 히어로 전체를 3D 장면으로 구성하고 제목·주요 입력·CTA는 HTML로 3D 위에 겹친다 |
| 태블릿 | 768~1279px | 풀 3D 히어로. PC와 같은 장면, 해상도 배율(DPR) 상한 1.5, 시점 이동은 터치·기울기 |
| 모바일 | 767px 이하 | 절충안. 제목·입력·핵심 정보는 HTML/SVG로 즉시 표시하고, PC 장면의 가벼운 축소판 3D는 첫 화면이 그려진 뒤 불러온다 |
| 공통 대체 | 모든 기기 | WebGL 미지원, 저사양, `prefers-reduced-motion`이면 3D 대신 같은 장면의 정지 렌더 이미지(AVIF/WebP). 운영 킬 스위치 `NEXT_PUBLIC_HERO3D_ENABLED=false`도 같은 정지 이미지로 대체한다(랜딩이 없는 admin-suite는 변수를 두지 않는다) |

- 기기 판정은 화면 폭과 기기 성능을 함께 본다. 폭이 태블릿이라도 저사양이면 모바일 절충안으로 내린다.
- 모바일은 가벼운 3D를 자동으로 불러오는 방식을 유지한다(사용자 결정 2026-10-13). 단, 불러오기 전에 아래 저사양 판정을 먼저 한다.

### 1.1 저사양 판정 (로딩 전, 제안)

로딩 전에 아래 신호를 조합해 판정하고, 하나라도 해당하면 3D를 불러오지 않고 정지 이미지를 쓴다.

| 신호 | 판정 | 비고 |
|---|---|---|
| `navigator.connection.saveData` | true면 3D 로딩 생략 | 지원 브라우저에서만 읽힌다 |
| `prefers-reduced-motion: reduce` | 해당하면 3D 로딩 생략 | 접근성 규칙 |
| WebGL 사용 가능 여부 | 컨텍스트 생성 실패면 정지 이미지 | 작은 캔버스로 시험 생성 |
| GPU 등급 | WebGL 렌더러 문자열(`WEBGL_debug_renderer_info`)로 소프트웨어 렌더러(SwiftShader, llvmpipe 등)와 알려진 저사양 GPU 등급을 낮음으로 분류 | 문자열 목록은 구현 시 관리하며 마스킹된 값이면 다른 신호에 의존 |
| `navigator.deviceMemory`, `hardwareConcurrency` | 값이 있고 4 이하면 낮음 | `deviceMemory`는 Safari·Firefox에 없다. **undefined를 고사양으로 간주하지 않는다**(다른 신호로 판정) |

- "첫 1초 평균 프레임"은 로딩 전 판정 기준으로 쓰지 않는다(이미 불러온 뒤라 늦다). 런타임 강등에만 쓴다: 로딩 후 프레임이 30fps 아래로 지속되면 3D를 멈추고 정지 이미지로 내린다.
- iOS Safari의 기울기(DeviceOrientation) 입력은 사용자 제스처(버튼 탭)로 권한을 요청해야 한다. 권한 요청 없이 자동으로 기울기를 쓰지 않고, 거부하거나 미지원이면 터치·포인터 이동으로 대체한다.

## 2. 성능 예산 (제안)

| 항목 | PC·태블릿 | 모바일 |
|---|---|---|
| 3D 번들 + 에셋(압축 후) | 1MB 이하 | 300KB 이하 |
| 프레임 | 60fps | 30fps 이상 |
| LCP | 2.5초 이하 | 2.5초 이하 |
| 메인 스레드 차단 | 첫 화면 전 3D 초기화 0ms(동적 import) | 같음 |

three.js 코어만 gzip 약 150KB다. 모바일 예산 300KB는 코어 + 장면 + 에셋을 합친 값이므로 모바일 장면은 도형 몇 개와 단순 재질로 한정한다. 예산을 넘으면 정지 이미지로 대체한다(수치는 구현 시 번들 분석으로 확인).

## 3. 구현 규칙

| 항목 | 규칙 |
|---|---|
| 스택 | three.js + React Three Fiber + drei(Next.js) |
| 로딩 | 3D 캔버스는 동적 import(`ssr: false`). 첫 화면 HTML이 먼저 그려진 뒤 로드한다 |
| 렌더링 | 화면 밖으로 나가면 렌더링을 멈춘다(`frameloop="demand"` 또는 IntersectionObserver). 탭이 숨으면 정지 |
| 형상 | 가능하면 코드로 생성하는 도형(고리, 원통, 평면)으로 만든다. 외부 모델은 glTF + Draco/Meshopt 압축, 텍스처는 KTX2 |
| 오버레이 | 제목·입력·CTA는 HTML(검색 노출, 스크린리더, LCP). 3D 캔버스는 `aria-hidden` |
| 색 | 각 제품 토큰 플랜(03장 4.3)에서 고른다. 3D 재질 색도 토큰 밖의 색을 쓰지 않는다 |
| 피할 인상 | 각 제품 `REFERENCES.md`의 "피할 인상"을 지킨다(예: 보라/핑크 그라디언트, 별 파티클, 흔한 지구본·네온 그리드) |
| 접근성 | `prefers-reduced-motion`이면 정지 이미지. 자동 회전·흔들림은 사용자가 끌 수 있게 한다 |

### 3.1 공용 3D 장면 키트 (`packages/ui-3d`, 제안)

12개 제품이 같은 기반을 쓰면 번들·품질·성능 관리를 한 곳에서 할 수 있어 예산에 맞추기 쉽다.

| 구성 | 내용 |
|---|---|
| 로더 | 동적 import, 저사양 판정(1.1절), 화면 밖 정지, 런타임 강등을 한 번에 처리하는 래퍼 |
| 재질 | 제품 디자인 토큰(Tailwind CSS v4 `@theme` 값)에서 색을 읽어 만드는 재질. 토큰 밖 색 금지 |
| 조명 | 표준 조명 세트(PC용, 모바일 축소용) |
| 대체 이미지 | 같은 장면의 정지 렌더 이미지를 보여 주는 컴포넌트(AVIF/WebP, 크기 지정으로 레이아웃 이동 방지) |
| 성능 모니터 | 프레임 측정과 강등 신호. 개발 모드에서 예산 초과 경고 |

제품은 키트 위에 제품 소재(5장)만 얹는다.

## 4. 수용 기준 (모든 제품 랜딩 작업에 공통)
- PC·태블릿에서 풀 3D, 모바일에서 절충안, 대체 조건에서 정지 이미지가 각각 동작한다.
- 성능 예산을 Lighthouse(모바일·데스크톱)와 프레임 측정으로 확인한다.
- 저사양 판정(1.1절)이 로딩 전에 동작하고, `deviceMemory`가 없는 브라우저(Safari, Firefox)에서도 정지 이미지 또는 3D로 올바르게 분기한다.
- 제목·입력·CTA가 3D 로딩 전에 보이고, 키보드와 스크린리더로 쓸 수 있다.
- 레퍼런스 대비 스크린샷을 PC·태블릿·모바일 3종으로 남기고 고문(Fable) 디자인 검토를 통과한다.

## 6. 선택 단계: 3D 영상 (제품 선택, 2026-10-14 추가)

1절 "공통 대체"는 3D를 못 돌리면 바로 정지 이미지로 내린다. 제품이 원하면 그 사이에 같은 장면을 미리 렌더한 영상 단계를 둘 수 있다. 처음 채택한 제품은 nomad-docs다(`03_SCREENS_UX.md` 4.6.1절, DC-F-049).

| 단계(위에서부터 시도) | 조건 | 보여 주는 것 |
|---|---|---|
| 1 실시간 3D | 1절 PC·태블릿 조건, 저사양 아님(1.1절), WebGL 정상, 킬 스위치 켜짐 | 실시간 장면 |
| 2 3D 영상(선택) | 모바일, 저사양, WebGL 실패, 런타임 30fps 미만 강등 | 실시간 장면을 같은 코드로 오프라인 렌더한 8~12초 무음 루프 영상 |
| 3 정지 이미지 | `prefers-reduced-motion`, 데이터 절약 모드, 영상 로드 실패, 영상 킬 스위치 꺼짐 | 1절 정지 렌더 이미지 |

| 항목 | 규칙 |
|---|---|
| 예산 | 영상 2MB 이하(모바일 1MB 이하), 포스터 이미지가 LCP 요소, 첫 화면 JS에 3D·영상 코드 0(동적 import), CLS 0(크기 고정) |
| 재생 | `autoplay muted loop playsinline`, 포스터 지정, 화면 밖·탭 숨김이면 일시정지, 키보드로 조작할 수 있는 재생/일시정지 버튼 |
| 제작 | 실시간 장면 코드에서 프레임을 뽑아 인코딩한다. 장면이 바뀌면 영상도 다시 만든다. 생성형 영상 도구는 제품 결정 확인 전에는 쓰지 않는다 |
| 킬 스위치 | 제품별 `NEXT_PUBLIC_HERO_VIDEO_ENABLED`(꺼지면 3단계로) |
| 수용 기준 | 4절 기준에 더해 영상 재생 확인과 자동재생 차단 환경(저전력 모드 iOS 등)에서 포스터 + 재생 버튼 표시 확인 |
