# 03 화면과 UX: FLORA Publishing

2026-10-13 개정: AI 채팅·음성·설정집 화면(3.1절), 디자인 시스템(3.2절), 3D 히어로(4.6절)를 더했다. **메인페이지 히어로는 2026-10-13 사용자 결정(확정 결정 15, `docs/reference/00_MERGE_ANALYSIS.md:23`)으로 "판면 정지 렌더 + 판형 전환 1회"에서 3D로 바뀌었다.** 기기 구성·성능 예산·대체 화면은 `docs/file/03-설계/디자인/HERO_3D.md`를, 디자인 시스템은 `docs/file/03-설계/디자인/DESIGN_SYSTEM.md`를 따른다.

작성일 2026-10-12. 화면 구성의 원본은 `Flora-v2/DESIGN.md`(아래 v2 DESIGN)와 `Flora-v2/PRD.md` 3.1절. 메인페이지는 `docs/file/03-설계/디자인/DESIGN_PRINCIPLES.md`(아래 DP) 절차를 따른다. 모든 UI 문구는 한국어(`Flora-v2/CLAUDE.md` UI 텍스트 규칙).

### 2.1 가입 → 부트스트랩 → 첫 책
