# 01 PRD: Toon Factory

작성일 2026-10-12. 원본 기획(`Toon-Factory/PRD.md` 32줄)은 기능 이름만 있고 수용 기준, 요금 수치, 데이터 구조가 없다(`docs/reference/reviews/Toon-Factory.md:21-24`). 이 문서의 수치와 정책 중 원본·리뷰·분석에 근거가 없는 것은 "제안"으로 표시하고 이유를 단다. 외부 사실(플랫폼 규격, 법령 세부, 모델 약관)을 확인하지 않은 것은 "미확인"으로 표시한다.

2026-10-13 개정: AI 계층, 음성, 3D 히어로, 디자인 시스템(확정 결정 13~17, `docs/file/03-설계/공용코어/AI_ARCHITECTURE.md:3`)을 MVP에 넣었다. 추가한 곳은 2절(범위 행), 3.6절(TN-F-050~062), 4.1·4.2절(features 키), 4.6절(AI·음성 크레딧 단가), 5절(AI 수치), 6.7절(AI·음성 개인정보와 대화 규칙), 7절(K9~K11), 8절(D9~D17)이다. 기존 TN-F 번호와 크레딧 단가(콘티 3, 대사 1, 배경 4/장, MP4 3)는 바꾸지 않았다. 바뀐 것은 기존 AI 기능(TN-F-020~022)의 생성 경로가 공용 LLM 게이트웨이에서 FastAPI 그래프로 옮겨진 점뿐이다(3.6절). AI 생성 표시(TN-F-035)와 이미지 생성 저작권·금지 대상 규칙(6.2·6.3절)은 그대로 유지한다.

2026-10-13 2차 개정(확정 결정 20, 경쟁 도구 벤치마킹 `08_BENCHMARK.md`): 로그라인·시놉시스 생성기(TN-F-024)와 플랫폼 내보내기 프리셋(TN-F-038, 8절 D3 해소)을 MVP에 넣고, 브랜디드 툰(협찬 등록·광고주 확인·대가성 문구·가상인물 표시, 3.7절 TN-F-070~073)을 MVP 차별화 기능으로 추가했다. SNS 직접 업로드는 Phase 3에서 Phase 2로 당기고(TN-F-080, video sns-uploader의 `naver_clip` 포함), 숏툰 모션·자막은 Phase 2 기능(TN-F-081)으로 구체화했다(3.8절). 바뀐 곳은 2절, 3.3·3.4·3.7·3.8절, 4.1~4.3절(`sponsorship` 키, 로그라인 단가), 6.4·6.8절, 7절(K12~K13), 8절(D3, D6, D16, D18~D21)이다. 캐릭터를 AI가 그리지 않는다는 원칙(J1)은 그대로다. 2026-10-14 개정(확정 결정 22, `docs/file/03-설계/공용코어/AUTH_ROADMAP.md`): 로그인을 단계로 켠다. 바뀐 곳은 2절 머리말, TN-F-040, 6.1절 수집 항목, 6.6절, 8.1절(새 절)이고 기존 가입 수단(이메일 + Google)과 공개 가입 정책은 그대로다.
