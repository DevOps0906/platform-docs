# develop — 제품별 개발 묶음

폴더 1개가 프로젝트 1개입니다. 각 폴더에는 개발 안내서(`<제품>_develop.md`), 설치 스크립트(`setup-<제품>.sh/.ps1`),
개발 폴더에 붙는 묶음(`<제품>-root/`)이 같은 형식으로 들어 있습니다. 개발은 이 저장소가 아니라 setup 스크립트가 만드는
`D:\WorkSpace\DEV\<제품>\` 폴더에서 합니다(맨 위 [README](../README.md) 4절).

## 공용

| 폴더 | 내용 |
|---|---|
| [`_shared/`](_shared/) | 모든 제품이 같이 쓰는 설치 가이드와 도구: Dify(AI 채팅 서버), LLM 키·오픈소스 LLM 서버·라우팅, 음성 서버, 개발 위키 스킬 원본, 묶음 생성 스크립트 `build_root.py` |
