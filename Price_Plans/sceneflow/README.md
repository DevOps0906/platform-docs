## 2. 흐름

```
준비: 스토리보드 시트 템플릿(03 3장) + 주제 2개 선정
   ↓
① 본인 한국사 채널: 롱폼 1편 + 쇼츠 5편 → 업로드 → 작업 기록표(03 11장)
   ↓                         (같은 주에 롱폼 1편을 크몽 샘플로)
② 크몽 등록(02) + 커뮤니티 홍보(04 4장)
   ↓
주문 → 접수 양식(04 1장) → 수작업 제작(03) → 납품 → 인터뷰(04 3장)
   ↓
① 롱폼 2편째 + 쇼츠 5편 → 7일 지표 수집
   ↓
4주 끝 판정(01 3장)
   ├ GO   → Track S 개발 착수(products/sceneflow/06_AGENT_PLAN.md 2026-10-18 새 장, VID-06-066부터)
   ├ 수정 → 실패한 가설만 바꿔 2주 더
   └ 중단 → 대행 상품 내림, Track S는 본인 채널용 최소 범위만 검토
```

## 3. 같은 규칙을 쓰는 곳

수작업 제작도 제품과 같은 규칙을 지킨다: 장면 길이 합계는 목표 ±10%, 사실을 주장하는 장면에는 출처를 붙이고 출처가 없으면 경고 목록에 올린다(VD-F-138), 실존 인물(역사 인물 포함) 얼굴을 AI로 만들지 않는다, 원본 클립·사진은 권리 근거를 기록한다(VD-F-134), AI 생성 소재 표시, 보장 표현·근거 없는 수치·가상 후기 금지(`products/sceneflow/01_PRD.md` 6장, 10장). 렌더는 FFmpeg 기준으로 제품을 설계하지만, 개발 전 수작업 단계에서는 이미 쓰는 편집 도구를 써도 된다(03 8장).
