# Web-App-Agency — 웹/앱 에이전시 + 네이버 블로그 스킨

작성일 2026-10-14. 상태: 초안. 대표님과의 기획 대화(2026-10-14)를 정리한 서비스 사업 문서입니다.

## 1. 한 줄 정의

**"전환형 모션 웹 스튜디오"**: 동적 히어로섹션 웹사이트를 주전공으로, 멋있어서 문의가 늘어나는 사이트를 만들고 그 문의(리드)까지 운영해 주는 1인 AI 가속 에이전시. 네이버 블로그 스킨은 진입 상품으로 함께 판다.

| 항목 | 내용 |
|---|---|
| 브랜드 | NOMAD AI Factory |
| 주 고객 | 소상공인·1인 사업자(병원, 학원, 필라테스 등), 브랜드를 리뉴얼하려는 중소기업, MVP가 필요한 초기 스타트업 |
| 강점 | 실서비스 SaaS 다수 운영 경험(포트폴리오), Next.js·Supabase 스택, AI 멀티에이전트 개발 |
| 약점 | 에이전시 운영 경험 없음(수주·견적·범위 관리·수금) → `04_OPERATIONS.md` 템플릿으로 보완 |

## 2. 상품 사다리

```
[진입]   네이버 블로그 스킨 / 히어로 섹션 단품
   ↓
[주력]   모션 랜딩 / 인터랙티브 브랜드 사이트
   ↓
[고단가] 웹앱 MVP (웹 납품 5~10건 이후 선별 수주)
   ↓
[반복]   유지보수 → 리드 운영 구독   ← 진짜 수익원
   ↓
[제품화] 리드 대시보드·스킨 생성기 SaaS, 화이트라벨
```
