# 가격 플랜: 웹/앱 에이전시 (Web-App-Agency)

상태: 초안 · 작성일 2026-10-14 · 최종 수정일 2026-10-14

모든 가격은 VAT 별도이며, 근거가 시장 단가 외에 없는 값은 제안이다. 첫 판매 결과로 고친다.

## 1. 한 줄 정의와 고객

동적 히어로섹션 웹사이트를 주전공으로 하는 1인 AI 가속 에이전시. 사이트 제작 → 리드 수집 → 운영 구독으로 이어지는 구조로 판다(`README.md` 2장).

| 고객 유형 | 상황 | 주 상품 |
|---|---|---|
| 소상공인·1인 사업자 | 블로그·플레이스만 있고 홈페이지가 없음 | 블로그 스킨, 템플릿 랜딩, 업종 패키지 |
| 리뉴얼 중소기업 | 오래된 사이트, 문의가 줄어듦 | 히어로 단품, 모션 랜딩, 브랜드 사이트 |
| 초기 스타트업 | 검증용 MVP 필요, 정부지원금 집행 | 웹앱 MVP(중기 이후) |

## 6. 단계별 가격 계획

### 6.1 초기 (0~3개월): 리뷰 확보

목표: 리뷰 20건, 월 매출 200~300만원. 크몽·숨고에 진입 상품부터 등록한다.

| 코드 | 상품 | 라이트 | 스탠다드 | 프리미엄 | 포함 범위 |
|---|---|---|---|---|---|
| AG-BS | 네이버 블로그 스킨(T1) | 5만원 | 12만원 | 25만원 | 라: 기본 스킨 + 모바일 커버 / 스: 홈페이지형 + 위젯 5개 + 카테고리 링크 / 프: 위젯 10개 + 플레이스 이미지·썸네일 + 원본 파일. 수정 1/2/3회. 진입 상품, 공식 미달 |
| AG-HR | 히어로 섹션 단품 | 50만원 | 90만원 | 150만원 | 라: Lv1 모션 / 스: Lv2 스크롤 연출 / 프: Lv3 3D(HERO_3D 표준 대체 화면 포함). 기존 사이트에 삽입 |
| AG-LP | 템플릿 랜딩(T2) | 39만원 | 69만원 | 99만원 | 원페이지, 반응형, 기본 SEO, 문의폼(L0) |
| AG-ML | 모션 랜딩(T3) | 99만원 | 140만원 | 190만원 | 원페이지 + Lv1~2 연출 + 리드 L0. 프리미엄은 L1 포함 |
| AG-BR | 인터랙티브 브랜드 사이트(T4) | 250만원 | 350만원 | 500만원 | 5~7페이지 + Lv2~3 히어로 + 리드 L1 |
| AG-IM | 몰입형 프리미엄(T5) | 600만원~ | 별도 견적 | 별도 견적 | Lv4 셰이더·커스텀 3D |

| AG-AP | 모바일 앱 MVP(T7) | 별도 견적 | - | - | 초기 판매 안 함 |

런칭 할인: 첫 10건 한정 20~30% 할인 + 유지보수 스탠다드 첫 달 무료(구독 전환율 측정용). 할인 규칙은 공용 원칙 6장.
