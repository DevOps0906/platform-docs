# 05 실행 로드맵과 KPI

작성일 2026-10-14. 린 검증 우선: 자체 사이트·SaaS를 만들기 전에 판매 채널에서 먼저 팔아 본다.

## 1. 실행 순서

| 시점 | 할 일 | 완료 조건 |
|---|---|---|
| 1주차 | 대표님 네이버 블로그(디지털노마드연구소)를 홈페이지형으로 리뉴얼 → 포트폴리오 1호 | 스킨 적용 완료 |
| 1~2주차 | 히어로 데모 4종 제작(Lv2 스크롤 3종 + Lv3 3D 1종), 15~30초 영상 녹화 | 영상 4개 |
| 2주차 | 크몽·숨고에 블로그 스킨(AG-BS), 히어로 단품(AG-HR), 템플릿 랜딩(AG-LP) 등록 | 상품 3개 승인 |
| 2~4주차 | 인프라 셋업: Vercel Pro 팀 1개, Supabase Pro 조직 1개, 멀티테넌트 `leads` 테이블, 시트 동기화 n8n 워크플로우 | 테스트 리드 1건이 시트·알림까지 도착 |
| 1개월 | 계약서·요구사항정의서·견적서 템플릿 완성(nomad-docs로 생성) | 템플릿 3종 |
| 1~2개월 | 모션 랜딩 보일러플레이트 완성 | T3 실작업 10시간 이하 실측 |
| 3~6주차 | 할인가로 리뷰 확보, 모든 납품에 리드 L0 제안, 유지보수 첫 달 무료 | 리뷰 10건 |
| 7주차 | 문의 데이터로 첫 업종 결정(AG-D-1) | 결정 기록 |
| 3개월 | 리뷰 20건 → 중기 가격으로 인상, 업종 패키지 출시 | 게이트 통과 |
| 6개월 | 운영 구독 출시, 블로그 스킨 템플릿 판매 | 구독 고객 5명 |
| 12개월 | 스킨 생성기·리드 대시보드 SaaS 베타, 바우처 공급기업 등록 검토 | 베타 사용자 20명 |

## 2. KPI

| 지표 | 초기 목표(제안) | 중기 목표(제안) | 측정 방법 |
|---|---|---|---|
| 월 매출 | 200~300만원 | 600~1,000만원 | 정산 기록 |
| 리뷰 수 | 20건 | 50건 | 크몽·숨고 |
| 상담 → 계약 전환율 | 20% | 30% | 리드 DB 상태값 |
| 평균 객단가 | 60만원 | 150만원 | 계약 금액 |
| 유지보수 전환율 | 30% | 50% | 납품 고객 중 구독 고객 |
| 반복 매출 비중 | 10% | 30% 이상 | 구독 매출 / 전체 매출 |
| 실작업 시간 대비 견적 | 견적의 80% 이하 | 60% 이하 | 작업 로그 |

## 3. 연결되는 사업 기회

| 기회 | 내용 | 시점 |
|---|---|---|
| 콘텐츠 | "AI로 1인 웹에이전시 시작하기" 전자책·강의. 수주 과정 자체가 콘텐츠 | 중기 |
| 강의 차별화 | 기존 강의는 "스킨 직접 만들기". 대신 "블로그 스킨 부업으로 첫 매출 내기"(수주·가격·납품) | 중기 |
| 교차 판매 | 납품 고객에게 nomad-blog, nomad-commerce 구독 | 중기 |
| 정부지원 | 납품 실적·리드 데이터를 근거로 "소상공인 디지털 전환 AI 에이전트" 아이템 지원 | 장기 |
| 퍼널·CRM SaaS | 멀티테넌트 리드 DB를 제품으로 전환 | 장기 |
