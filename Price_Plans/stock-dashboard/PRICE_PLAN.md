# 가격 플랜: stock-dashboard (stock-dashboard)

상태: 초안 · 작성일 2026-10-14 · 최종 수정일 2026-10-14

장 구조는 [`../_common/PRICE_PLAN_TEMPLATE.md`](../_common/PRICE_PLAN_TEMPLATE.md)를 따른다. 공용 방법은 [`../_common/PRICING_PRINCIPLES.md`](../_common/PRICING_PRINCIPLES.md).

모든 가격은 VAT 포함(B2C SaaS, 공용 원칙 7장)이다. 이 문서는 PRD 가격을 바꾸지 않는다. 다른 값은 모두 "제안"이며 10장에서 결정한다. **유료 판매는 법률 의견서(PRD D-3)를 받기 전에는 열지 않는다.** 이 문서의 어떤 가격도 그 조건보다 우선하지 않는다.

## 1. 한 줄 정의와 고객

본인 증권 계좌를 조회 전용으로 연결해 보유·손익·비중과 매매 이력을 한 화면에 모으고, AI가 "무엇을 사라"가 아니라 "지금 어떤 상태인가"를 설명하는 개인 투자자용 대시보드(초대제 베타).

| 고객 유형 | 상황(PRD 1장 페르소나) | 주 플랜 |
|---|---|---|
| 직장인 투자자(지훈, 34) | 점심·퇴근 후 MTS 확인, 매매 기록을 엑셀에 수기 정리 | beta → pro |
| 초보 투자자(수연, 29) | 한두 종목 쏠림, 위험을 쉬운 말로 알고 싶다 | beta |
| 운영자(제품 소유자) | 법적 위험 없이 기능 검증, 사고 시 즉시 중단 | 해당 없음(운영) |

## 3. 원가 구조

AI 원가는 코어 seed 단가(`products/_supabase-modular/seed.sql:243-262`, 상용 LLM 1k 입력 1·출력 4, 오픈소스 0.2·0.5, STT 3/0.5 per 분, TTS 5/1 per 천 자)를 원가 지표로 쓴다. 이 제품의 판매 크레딧은 지표와 거의 1:1로 정해져 있다(채팅 1턴 5크레딧 ≈ 상용 지표 5~7, PRD 4.4절).

| 항목 | 원가 | 근거 |
|---|---|---|
| 원가 지표 1의 원화 | 5~20원 가정 | 제안·미확인. 실제 청구액(`core.ai_usage`)으로 첫 달에 교체 |
| 진단 1회 | 지표 약 10(재생성·투자 권유 금지 검사 포함) → 50~200원 | PRD 4.4절 정액 10 |
| 채팅 1턴 | 상용 지표 5~7 / 오픈소스 약 2 → 10~140원 | PRD 4.4절 |
| pro 월 600크레딧 전부 사용 | 지표 약 600 → 3,000~12,000원 | 최악 경우 |
| pro 월 평균 사용(50% 가정) | 지표 약 300 → 1,500~6,000원 | 제안 |
| 고객당 인프라(시세 중계 워커, DB, FastAPI) | 월 약 500원 가정 | 제안·미확인. 공용 원가 `../_common/COST_BASELINE.md` 1장 |
| 결제 수수료 | 카드 3.4% + VAT = 약 3.74% → 9,900원당 약 370원 | Toss Payments 공개 요율(https://www.tosspayments.com/about/fee, 확인일 2026-10-14). 가입비 22만원·연관리비 11만원(VAT 별도) 별도 |
| 증권사 API·DART | 0원(사용자 본인 키, 공개 API) | PRD 4.2절. 약관 미확인(D-10) |

70% 매출총이익률 점검(공용 원칙 4.2절): pro 9,900원(VAT 포함) → 순매출 9,000원 → 허용 원가 2,700원.

| 경우 | 원가 합계 | 통과 |
|---|---|---|
| 평균 사용, 지표 5원 | 1,500 + 500 + 370 = 2,370원 | 통과(74%) |
| 평균 사용, 지표 20원 | 6,000 + 870 = 6,870원 | 미달(24%) |
| 전부 사용, 지표 5원 | 3,000 + 870 = 3,870원 | 미달(57%) |

결론: 9,900원 + 600크레딧은 원가 지표가 5원 근처이고 오픈소스 경로 비중이 높을 때만 70%를 넘는다. 중기 가격 인상(6.2절) 또는 크레딧 축소가 필요하다(10장 SD-P-2).

## 6. 단계별 가격 계획

### 6.1 초기 (0~3개월)

현재 정본 그대로. 무료 초대 베타로 검증한다. 런칭 할인 없음(판매 자체가 열리지 않음).

| 코드 | 상품 | 가격(VAT 포함) | 포함 범위 |
|---|---|---|---|
| `default` | 기본 | 0원 | 기능 없음(베타 게이트) |
| `beta` | 초대 베타 | 0원 | 월 300크레딧, 2장 표 한도 |
| `pro` | 프로 | 9,900원/월(비활성) | 월 600크레딧. 법률 의견 수령 전 판매 금지 |

### 6.2 중기 (4~12개월)

전환 조건: 법률 의견서 수령(D-3) + 베타 사용자 30명 + 월 활성 60% 이상(제안). 유료 판매는 이 단계에서 처음 연다.

| 코드 | 상품 | 가격(VAT 포함, 제안) | 포함 범위 | 변경 |
|---|---|---|---|---|
| `default` | 무료(베타 종료 후) | 0원 | 증권사 연결 1, 대시보드·동기화, 진단 월 3회, 채팅 없음 | 기능 없음 → 제한 무료(제안) |
| `beta` | 초대 베타 | 0원 | 기존 베타 사용자만 유지, 6개월 뒤 `pro` 할인 전환 | 신규 발급 중단 |
| `pro` | 프로 | 14,900원/월, 연 149,000원 | 월 600크레딧, 기존 pro 한도 | 9,900원 → 14,900원. 원가 70% 미달(3장)과 시장 하단~평균 사이 위치 근거 |

판매 개시 할인: 베타 사용자 첫 3개월 9,900원(정가 대비 33%, 공용 원칙 6장 40% 이내).

### 6.3 장기 (1~3년)

| 코드 | 상품 | 가격(VAT 포함, 제안) | 포함 범위 | 변경 |
|---|---|---|---|---|
| `default` | 무료 | 0원 | 중기와 같음 | - |
| `pro` | 프로 | 14,900~19,900원/월 | 두 번째 증권사, 실계좌 조회, 3사 비교 포함 시 19,900원 | 기능 확장 시에만 인상. 알파스퀘어 스탠다드(19,800원)와 같은 선 |

상위 등급(예: 월 29,900원 리서치 플러스)은 새 플랜 코드가 필요하므로 이 문서에서 제안만 하고 10장에 둔다.
