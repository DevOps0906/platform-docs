## 2. 기획안 전달 메시지 (1일 차)

```
안녕하세요. 「{제목}」 기획안 3가지를 보내 드립니다.
원고를 읽고 독자가 처음 2초에 멈출 만한 문장을 골랐습니다. 인용 문장은 모두 원고와 글자 단위로 대조했습니다.

1안 ({각도}) 로그라인: …  첫 문장: …  인용: "…"(○장)
2안 ({각도}) …
3안 ({각도}) …

마음에 드는 안의 번호를 알려 주세요. 섞고 싶은 부분(예: 1안 첫 문장 + 2안 인용)도 말씀해 주시면 반영합니다.
결말·반전은 고르신 스포일러 수준({수준})에 맞춰 뺐습니다.
```

## 3. 고객 인터뷰 (납품 직후, 15분)

목적: 가설 H1~H4(`01_VALIDATION_PLAN.md` 1장) 확인. 녹음하면 녹음 사실을 먼저 알리고 동의를 받는다. 질문은 사실(과거 행동) 위주로, 칭찬 유도 질문을 하지 않는다.

| # | 질문 | 확인하는 가설 |
|---|---|---|
| 1 | 이 책 전에는 홍보 영상을 어떻게 만드셨나요? 비용과 시간은? | H1 대안·지불 기준 |
| 2 | 이번 주문을 결정한 이유 하나만 꼽는다면? | 차별점 |
| 3 | 기획안 3가지 중 고르신 안을 고른 이유는? 직접 쓰셨다면 어떤 문장을 고르셨을까요? | H2 |
| 4 | 결과물에서 가장 고치고 싶었던 부분은? | H3 |
| 5 | AI 이미지·음성이라는 점이 신경 쓰였나요? 어디서? | H3 |
| 6 | 이 영상을 어디에 올리셨나요(올리실 건가요)? | 규격 우선순위 |
| 7 | 다음 책이 나오면 다시 맡기실까요? 가격이 얼마면 망설이지 않으실까요? | H1, H4 |
| 8 | 직접 원고를 올리면 15분 안에 초안이 나오는 서비스가 월 29,000원이라면 쓰시겠어요? 아니면 지금처럼 맡기시겠어요? | 구독 대 대행 |
| 9 | 이 서비스를 알릴 만한 다른 작가·출판사가 있을까요? | 소개 경로 |
| 10 | 대기 명단(런칭 할인)에 이메일을 남기시겠어요? | 사전 예약 |

기록 양식(인터뷰 탭 열): 주문 번호, 날짜, 고객 유형(작가, 1인 출판사, 출판사 마케터, 웹소설 작가), 질문별 답 요약, 원문 인용(고객 동의 시), 재구매 의향(예/아니요/모름), 적정 가격 답, 대기 명단 여부.

## 4. 커뮤니티·직접 제안 글

커뮤니티 규칙(광고 게시 허용 여부, 게시판)을 먼저 확인하고, 홍보가 금지된 곳에는 올리지 않는다.

```
[작가·1인 출판사분들께] 원고로 만드는 북트레일러 샘플을 보여 드립니다

원고를 읽고 독자를 붙잡을 문장을 골라, 장르에 맞는 예고편으로 만드는 작업을 하고 있습니다.
같은 구성으로 쇼츠(세로), 유튜브(가로), 인스타(정사각) 영상을 함께 만듭니다.
샘플: {샘플 링크 3개}

AI 이미지와 AI 음성을 쓰고, 영상 끝에 AI 사용을 표시합니다.
인용 문장은 원고와 글자 단위로 대조하고, 결말·반전은 빼고 만듭니다.

30초 쇼츠 99,000원부터, 크몽에서 주문하실 수 있습니다: {크몽 링크}
궁금한 점은 댓글로 남겨 주세요.
```

출판사 직접 제안(이메일·메시지, 짧게):

```
안녕하세요, {출판사} 마케팅 담당자님. 신간 홍보 영상을 원고 기반으로 만드는 작업을 하고 있어 연락드립니다.
같은 책으로 쇼츠·유튜브·인스타 규격을 한 번에 만들고, 영상별 구매 링크 클릭 수를 측정해 드립니다.
샘플 3편: {링크}. 다음 신간 1종을 시범으로 맡겨 주시면 기획안(훅 3가지)까지는 무료로 보내 드리겠습니다.
```

시범 기획안 무료 제공은 출판사 대상에만, 4주 동안 최대 5곳으로 제한한다(제안). 기획안 작성 시간(1·2단계 약 30분)이 영업 비용이다.

## 5. 대기 명단(사전 예약) 안내

```
직접 원고를 올리면 기획안과 초안 영상이 바로 나오는 서비스를 준비하고 있습니다.
대기 명단에 이메일을 남기시면 출시 때 첫 3개월 월 19,900원(정가 29,000원) 할인 쿠폰을 보내 드립니다.
결제는 출시 후에 하시며, 대기 명단 등록은 결제가 아닙니다.
```

대기 명단은 개발 전에는 구글 폼 같은 무료 폼으로 받는다(이메일, 고객 유형, 1년 출간 종수). 개인정보 수집 항목·목적·보유 기간(출시 안내 후 삭제, 최대 1년, 제안)을 폼 첫 화면에 적는다. 가격·할인은 `PRICE_PLAN.md` 6.1절 런칭 할인과 같다.
