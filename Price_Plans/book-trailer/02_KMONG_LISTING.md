# 02 크몽 상품 등록 원고: AI 북트레일러 제작

작성일 2026-10-16. 상태: 초안(등록 전 대표님 검토). 카테고리 후보: 영상·사진·음향 > 출판업 영상(같은 카테고리에 북트레일러 외주가 있다: 글랩폰트 22만~66만 원, 우후스튜디오 6.6만~22만 원, `PRICE_PLAN.md` 4장). 가격은 `PRICE_PLAN.md` 6.1절 S-30·S-60·S-PRO와 같다.

등록 전 확인(미확인 항목): 제목·요약 글자 수 제한, 판매 수수료율, 패키지별 수정 횟수 입력 방식, 외부 연락처·외부 결제 유도 금지 규정. 모두 크몽 전문가 센터의 현재 운영 정책으로 확인한 뒤 이 원고를 맞춘다.

## 1. 제목과 요약

| 항목 | 원고 | 메모 |
|---|---|---|
| 제목(1안) | 원고를 읽고 만드는 AI 북트레일러, 쇼츠·유튜브 규격 동시 제작 | 차별점(원고를 읽는다)을 앞에 |
| 제목(2안) | 내 책 문장으로 만드는 북트레일러 쇼츠, 3일 완성 | 1인 작가 대상 |
| 제목(3안) | 신간 홍보 북트레일러, 세로·가로·정사각 한 번에 | 출판사 마케터 대상 |
| 요약 | 원고에서 독자를 붙잡을 문장을 골라 장르에 맞는 예고편으로 만들어 드립니다. AI 이미지·AI 음성을 쓰고, 영상 끝에 AI 사용을 표시합니다. | AI 사용을 숨기지 않는다(PRD 6.4절) |

1주차에 1안으로 시작하고, 2주차에 클릭 수가 낮으면 2안으로 바꿔 비교한다(제안).

## 2. 메인 이미지(썸네일) 문구

| 요소 | 내용 |
|---|---|
| 큰 글자 | 원고가 예고편이 됩니다 |
| 작은 글자 | 쇼츠 9:16 · 유튜브 16:9 · 인스타 1:1 |
| 그림 | 샘플 영상의 실제 프레임 3장(세로·가로·정사각)을 겹쳐 배치. 띠지 모양 형광 노랑 띠 하나(`08_DESIGN_SYSTEM.md` 3장 형광 밑줄 #F5D547) |
| 넣지 않는 것 | 별점·판매 수·"1위" 같은 숫자, 가상 인물 얼굴, 영화 필름 릴 클립아트 |

이미지에 AI로 만든 인물이 나오고 그 인물이 책을 추천하는 것처럼 보이면 추천·보증 심사지침(2026-06-01 시행)에 따라 "[가상인물]" 표시가 필요하다. 썸네일에는 인물을 넣지 않는 것으로 피한다.

## 3. 서비스 설명

> **이런 분께 맞습니다**
> - 신간을 냈는데 홍보 영상을 만들 시간과 예산이 없는 작가·1인 출판사
> - 같은 책으로 쇼츠·유튜브·인스타 규격을 따로 만들기 번거로운 출판사 마케터
> - 연재 회차마다 스포일러 없이 궁금증을 남기는 쇼츠가 필요한 웹소설 작가
>
> **무엇이 다른가요**
> 1. 원고를 먼저 읽습니다. 책 전체를 분석해 독자를 붙잡을 훅 3가지를 제안하고, 그중 하나를 고르시면 그 방향으로 만듭니다.
> 2. 영상에 쓰는 인용 문장은 원고와 글자 하나까지 대조합니다. 원고에 없는 문장을 "책 속 문장"으로 넣지 않습니다.
> 3. 장르에 맞는 예고편 문법을 씁니다. 소설은 분위기와 질문으로, 실용서는 문제와 해결로, 에세이는 문장 하나로 끝까지 끌고 갑니다.
> 4. 결말과 반전은 빼고 만듭니다. 스포일러 수준(없음 / 맛보기 / 설정까지)을 고르실 수 있습니다.
> 5. 하나의 구성으로 여러 규격을 만듭니다. 세로 쇼츠, 가로 유튜브, 정사각 인스타 영상이 같은 문장과 같은 분위기로 나옵니다.
>
> **작업 순서**
> 1. 주문 후 요청서 작성(원고 파일, 표지, 책 정보, 구매 링크)
> 2. 1일 차: 훅 3가지와 인용 후보를 담은 기획안 전달 → 하나 선택
> 3. 2일 차: 장면 구성표(장면별 문구·내레이션·그림 설명) 전달 → 확인
> 4. 3일 차: 영상 전달 → 수정 요청(패키지별 횟수)
> 5. 최종본 전달(영상 + 표지 이미지 + 자막 파일 + 플랫폼별 제목·설명 문구)
>
> **사용하는 것**
> AI 이미지 생성, AI 음성(내레이션), 상업 이용 라이선스를 확인한 배경음악, 무료 상업용 한글 서체. 영상 끝에 "AI 생성 이미지·음성 포함"을 표시합니다. 작가님 사진이나 직접 고른 이미지·음악을 쓰고 싶으시면 함께 보내 주세요.
>
> **꼭 확인해 주세요**
> - 원고·표지·책 정보를 영상에 쓸 권리가 있는 분(저자 본인 또는 저자·출판사의 허락을 받은 분)만 주문하실 수 있습니다.
> - 실존 인물(작가님 포함)의 얼굴은 AI로 만들지 않습니다. 인물은 실루엣·뒷모습·소품으로 표현합니다.
> - "베스트셀러", "○만 부" 같은 실적 문구는 근거(서점 순위 화면, 판매 자료)를 주셔야 넣을 수 있습니다. 할인 문구는 도서정가제 범위 안에서만 넣습니다.
> - 원고 파일은 작업에만 쓰고 납품 후 30일이 지나면 삭제합니다.

## 5. 수정·환불 기준

| 상황 | 처리 |
|---|---|
| 기획안 단계에서 취소 | 전액 환불(작업 시작 전) 또는 크몽 규정 |
| 기획안 선택 후 취소 | 기획안 비용으로 STANDARD 30%, DELUXE·PREMIUM 20% 공제(제안) |
| 수정 범위 | 문구·내레이션 교체, 장면 순서, 이미지 다시 만들기(장면당), 음악 교체 |
| 수정 범위 밖(새 주문) | 다른 훅으로 처음부터 다시 만들기, 영상 길이 변경, 규격 추가(옵션) |
| 권리 문제 | 고객이 권리 없는 자료를 보낸 것이 확인되면 작업을 멈추고 크몽 규정에 따라 처리 |

크몽 자체 취소·환불 규정이 이 표보다 우선한다. 등록 전 확인해서 맞춘다.

## 6. 자주 묻는 질문

| 질문 | 답변 |
|---|---|
| 원고 전체를 보내야 하나요? | 네. 훅과 인용을 원고에서 고르기 때문입니다. 출간 전 원고라면 공개해도 되는 범위를 알려 주세요. 그 밖의 문장은 영상에 쓰지 않습니다 |
| 어떤 파일을 받나요? | PDF, EPUB, DOCX, 한글(HWP는 PDF로 바꿔 주세요), TXT |
| 제 목소리로 내레이션할 수 있나요? | 녹음 파일을 보내 주시면 AI 음성 대신 쓸 수 있습니다. 목소리 복제는 하지 않습니다 |
| AI로 만든 티가 나나요? | 장르마다 그림 스타일을 하나로 고정해 장면끼리 어긋나지 않게 만듭니다. 영상 끝에는 AI 사용 표시가 들어갑니다 |
| 유튜브에 올려도 되나요? | 네. 배경음악은 상업 이용 라이선스를 확인한 곡만 씁니다. 같은 템플릿 영상을 반복해서 대량으로 올리면 플랫폼 정책에 걸릴 수 있어 책마다 구성을 바꿔 드립니다 |
| 다른 작가의 책도 만들 수 있나요? | 저자·출판사의 허락을 받은 경우에만 가능합니다 |
| 판매가 늘어나나요? | 판매를 약속하지 않습니다. 대신 PREMIUM은 영상별 구매 링크 클릭 수를 측정해 드립니다 |

## 7. 요청사항(주문 후 구매자가 채우는 양식)

주문 요청서 질문 전체는 `04_INTAKE_AND_INTERVIEW.md` 1장. 크몽 요청사항 칸에는 아래 5개만 필수로 둔다.

1. 책 제목, 저자, 출판사, 출간일(또는 예정일), 장르
2. 원고 파일과 표지 이미지(첨부)
3. 영상에 꼭 넣고 싶은 문장이나 장면(없으면 "없음")
4. 스포일러 수준: 없음 / 맛보기 / 설정까지
5. 권리 확인: "원고·표지·책 정보를 홍보 영상에 쓸 권리가 있습니다"에 동의

## 8. 등록 문구 점검표

- [ ] "1위", "최고", "보장", 판매 증가 약속, 가상 후기·별점 문구 없음(PRD 6.5절)
- [ ] AI 사용 사실과 엔드카드 표시를 설명에 적음(PRD 6.4절)
- [ ] 샘플 영상은 권리가 있는 책으로만 만든 실제 결과
- [ ] 썸네일·포트폴리오에 AI 인물이 추천하는 장면 없음(있으면 "[가상인물]" 표시)
- [ ] 외부 연락처·외부 결제 안내 없음(크몽 규정 확인)
- [ ] 가격·작업일·수정 횟수가 `PRICE_PLAN.md` 6.1절과 같음
