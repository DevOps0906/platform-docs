# 가격 플랜: NOMAD Book Trailer (book-trailer)

상태: 초안 · 작성일 2026-10-15 · 최종 수정일 2026-10-15

장 구조는 [`../_common/PRICE_PLAN_TEMPLATE.md`](../_common/PRICE_PLAN_TEMPLATE.md)를 따른다. 공용 방법은 [`../_common/PRICING_PRINCIPLES.md`](../_common/PRICING_PRINCIPLES.md).

가격은 모두 원화, VAT 포함(B2C SaaS 기본, 공용 원칙 7장)이다. 달러 가격은 원문 그대로 적고 원화 환산은 1달러 = 1,400원(`../_common/COST_BASELINE.md` 3장 계획 환율)이다. 경쟁 가격 외에 근거가 없는 값은 "제안", 확인하지 못한 외부 사실은 "미확인"이다.

## 1. 한 줄 정의와 고객

원고를 넣으면 훅 브리프 → 장르 문법 스토리보드 → 이미지·내레이션·자막·음악 → 4개 규격 렌더 → 구매 링크 클릭 측정까지 한 번에 하는 북트레일러 자동화 SaaS.

| 고객 유형 | PRD 페르소나 | 상황 | 주 플랜 |
|---|---|---|---|
| 1인 출판사·작가 | 김서연(42, 1인 출판사 대표 겸 작가) | 연 4~6권, 외주 영상은 권당 22만 원 이상이라 부담 | `creator` |
| 중소 출판사 마케터 | 박도윤(35, 월 신간 6~10종) | 규격 4종, 저자 승인, 영상별 성과 측정 | `publisher` |
| 웹소설·전자책 작가 | 이하은(29, 주 1~2편 쇼츠) | 스포일러 없이 꾸준한 쇼츠 | `free` → 크레딧팩 → `creator` |

출처: [`products/book-trailer/01_PRD.md`](../../products/book-trailer/01_PRD.md) 1장.

60초 creator 세트(94cr) 원가 추정(상용 브리프 + EL 내레이션 + 이미지 8장 + 렌더 2개): 분석 100 + 브리프 85 + 스토리보드 60 + 이미지 8장 480 + 내레이션 8장면 160 + 렌더 2개 50 + 메타 20 ≈ 955원. 크레딧당 약 10.2원(제안).

공용 원칙 4.2절 점검(목표 매출총이익률 70%, 제안):

| 점검 | 계산 | 결과 |
|---|---|---|
| 크레딧 하한(세트 평균) | 10.2원 / 0.3 = 34원 | 팩 35~39.7원 통과, `pack_3000`(31.7원)과 `publisher`(33원)는 경계 아래 |
| 크레딧 하한(이미지 최악 70원/3cr) | 23.3원 / 0.3 = 78원 | 모든 상품 미달. 이미지 비중이 높은 트레일러는 마진이 낮다. 이미지 모델 선택(schnell 계열 기본)과 베타 실측으로 보정(10장 TR-P-3) |
| `creator` 월 구독(800cr 전부, 크레딧당 12원) | 원가 9,600 + 인프라 2,500 + 수수료 1,085 = 13,185원 / 순매출 26,364원(VAT 제외) | 매출총이익률 약 50%. 사용률 50%면 약 68% |
| `publisher` 월 구독(3,000cr 전부, 12원) | 36,000 + 2,500 + 3,703 = 42,203원 / 순매출 90,000원 | 약 53%. 사용률 50%면 약 73% |

결론: 문서·텍스트 중심 작업은 마진이 높고, 원가의 절반 이상이 장면 이미지다. 가격 인상보다 이미지 기본 모델 선택, 사용자 이미지 업로드(0cr) 유도, 베타 4주 원가 측정(PRD D-4)으로 먼저 보정한다.

인사이트:

- 외주 북트레일러는 편당 6.6만~66만 원이고 크몽 같은 카테고리("출판업 영상")가 따로 있을 만큼 수요가 확인된다. 우리 경쟁 상대는 범용 AI 도구보다 이 외주 시장이다.
- 범용 AI 숏폼 도구는 원고를 읽지 않고 대본·주제에서 시작한다. "원고 대조 인용, 스포일러 수준, 장르 문법, 구매 링크 클릭"은 비교 대상이 없다.
- 출판사는 편당 외주비로 사고하므로 판매 페이지는 "월 구독 = 외주 1편 값의 1/8~1/2"처럼 편당 환산으로 보여 준다.
- 외주 시장 자체를 S 모델(대행)로 먹을 수 있다: 같은 엔진으로 우리가 납품하면 원가 1천 원대 작업을 9.9만 원에 판다(5장).

## 6. 단계별 가격 계획

### 6.1 초기 (0~3개월)

목표: S 대행 10건 + 유료 구독 20곳, 첫 달 해지율 10% 이하. PRD 가격을 그대로 쓰고 대행으로 검증·매출을 먼저 만든다.

| `free` | 무료 | 0원 | 가입 60 크레딧(30초 쇼츠 1편 체험), 워터마크 |
| `creator` | 크리에이터 | 29,000원. 런칭 할인 첫 3개월 19,900원(약 31%, 선착순 100명, 쿠폰) | 월 800 크레딧(60초 세트 약 8편) |
