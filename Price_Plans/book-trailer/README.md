
## 3. 같은 규칙을 쓰는 곳

수동 제작도 제품과 같은 규칙을 지킨다: 권리 확인 없으면 시작하지 않는다, 인용은 원고와 글자 단위로 대조, 1개 80자·합계 300자, 근거 없는 실적·보장·가상 후기·도서정가제 위반 할인 문구 금지, 실존 인물 얼굴 금지, 엔드카드 AI 표시, 같은 목소리·같은 이미지 스타일(`products/book-trailer/01_PRD.md` 6장, `08_DESIGN_SYSTEM.md`).
