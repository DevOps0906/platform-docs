# 08 숏폼 대행 운영: ShortsFlow (shortsflow)

2026-10-13 작성(확정 결정 21: 직접 대행 + 내부 도구). 운영사가 고객사 대신 숏폼을 기획·제작하고 채널(YouTube Shorts, 네이버 클립, IG Reels, TikTok)에 올리고 월간 리포트를 보내는 사업의 운영 기준이다. 제품 기능은 `01_PRD.md` 3.1절(VD-F-120~126), 계약·견적 문서 생성은 nomad-docs `shorts_agency` 패키지가 맡는다. 근거 없는 값은 "제안", 외부 사실을 확인하지 않은 값은 "미확인"으로 표시한다. 법률 문구는 변호사 검토 전 초안이다.

## 1. 사업 범위

| 항목 | 내용 |
|---|---|
| 형태 | 직접 대행. 운영사 팀이 shortsflow(Advanced, `features.agency`)를 내부 도구로 쓴다. 고객은 로그인하지 않고 승인 링크와 리포트 PDF만 받는다 |
| 대상 고객 | 숏폼 채널을 직접 운영할 인력이 없는 중소 브랜드, 스마트스토어·쿠팡 셀러, 지역 매장, B2B 제품사 |
| 채널 | YouTube Shorts, 네이버 클립, Instagram Reels, TikTok(Threads는 선택) |
| 하지 않는 것 | 조회수·구독자·매출 보장, 구독자·조회수 구매, 계정 매매, 타인 저작물 무단 재가공(Track A 원본 재편집은 고객이 권리를 가진 소재만) |
| 확장 | 외부 대행사에 도구 판매(화이트라벨, 고객 포털)는 Phase 2(01장 D-24). 직접 대행 고객 10곳 이상 운영 뒤 검토 |

## 2. 서비스 패키지와 가격 근거

| 패키지(`clients.package_code`) | 포함 | 제외 | 월 편수 기준(제안) | 가격(제안) |
|---|---|---|---|---|
| 제작만(`produce`) | 기획안·대본, 편집·자막·더빙(KO, 선택 JA/EN), 썸네일, 플랫폼별 리사이즈, 수정 2회 | 업로드, 채널 운영, 리포트 | 8편 | 편당 15만 원(8편 이상 12만 원) |
| 제작 + 업로드(`produce_upload`) | 위 + 고객 승인 링크, 예약 업로드, 제목·해시태그·대가성 문구, 월간 리포트 | 댓글 관리, 광고 집행 | 12편 | 월 180만 원 |
| 풀 운영(`full_ops`) | 위 + 채널 기획(시리즈·톤), 트렌드 레이더 소재 제안, 댓글 1차 응대(영업일 24시간 이내), 월간 개선 회의, 브랜드커넥트·제휴 캠페인 연결 | 촬영 출장(별도 견적), 광고비 | 20편 | 월 350만 원 |
| 옵션 | 촬영(반나절/하루), 출연자 섭외, 추가 언어판, 추가 수정, 긴급 납기(48시간) | - | - | 별도 견적 |

## 3. 운영 프로세스 (7단계)

| 단계 | 내용 | 산출물(nomad-docs 문서) | 도구(shortsflow) |
|---|---|---|---|
| 1 상담·브리프 | 목적(인지·매출·리드), 타깃, 채널, 예산, 참고 영상, 금지 표현 | 서비스 소개서, 콘텐츠 브리프 | - |
| 2 제안·견적 | 채널 전략, 편수, 일정, KPI 정의, 가격 | 제안서, 견적서 | 레이더(소재 근거) |
| 3 계약 | 계약 체결, 계정 접근 위임, 비밀유지 | 영상 제작·채널 운영 대행 계약서, NDA, 채널 계정 접근·운영 위임 동의서 | `clients` 등록, `client_channels` 연결 |
| 4 착수 | 브랜드 가이드 수령·확인, 월 콘텐츠 캘린더 | 과업지시서, 브랜드 가이드 확인서, 월 콘텐츠 기획안 | 위키에 고객 가이드 등록(VD-F-122) |
| 5 제작·검수 | 대본 → 제작 → 내부 검수 → compliance 검사 | (내부) 광고 표시 준수 체크리스트 | 생산(Track B/C), compliance 게이트 |
| 6 고객 승인·게시 | 승인 링크 → 승인 또는 수정 요청(정해진 횟수 안) → 예약 게시 | 수정·변경 요청서(한도 초과 시), 검수확인서(월 마감) | 고객 승인(VD-F-123), 업로드 |
| 7 리포트·개선 | 월간 리포트 발송, 다음 달 계획 회의, 청구 | 월간 성과 리포트, 청구 내역(세금계산서) | 월간 리포트(VD-F-124) |

## 5. KPI와 월간 리포트

KPI는 계약 시점의 기준선(베이스라인)을 잡고 분기마다 목표를 조정한다. 조회수·구독자 수를 보장하지 않는다(6장).

| 축 | 지표 | 출처 | 비고 |
|---|---|---|---|
| 도달 | 조회수, 노출 대비 조회 비율 | `analytics_snapshots`(플랫폼이 주는 것만) | 네이버 클립 통계 수집 경로는 미확인(업로더 `capabilities`에 통계 없음). 수집 전까지 "미제공" |
| 시청 품질 | 평균 시청 시간, 완주율 | 같음 | 완주율은 제공 플랫폼만 |
| 성장 | 구독자 순증, 영상당 구독 전환 | 채널 지표 | 수집 플랫폼만 |
| 운영 준수 | 업로드 준수율(게시 / 계약 편수), 승인 리드타임, 댓글 응답 시간 | `uploads`, `clients.monthly_quota`, `client_reviews` | 운영사 책임 지표. 목표 95%(제안) |
| 수익 | 제휴 클릭, 브랜드커넥트 선정 수 | `core.affiliate_clicks`, `core.brandconnect_applications` | 해당 고객만 |

월간 리포트 목차(`client_report.build` PDF):

1. 요약: 핵심 KPI와 전월 대비 증감, 목표 달성률
2. 업로드 현황: 계약 편수 대비 게시 편수, 채널별 표
3. 상위·하위 영상 3개: 소재, 훅, 길이, 썸네일별 성과와 해석
4. 시청자: 시청 시간, 트래픽(제공 플랫폼만)
5. 운영 이슈: 수정 요청 횟수, 승인 지연, 플랫폼 정책 경고
6. 다음 달 계획: 소재 후보, 실험 항목(A/B), 고객에게 필요한 자료·승인

## 6. 필요 문서 (nomad-docs `shorts_agency` 패키지)

계약류는 nomad-docs의 `risk_level=high` 문서라 템플릿 기반으로만 만들고 법률 검토 게이트(nomad-docs D-3)를 거친다. 문체부가 고시한 "영상 제작 표준계약서"나 MCN 전용 표준계약서는 2026-10-13 조사에서 확인하지 못했다(미확인). 방송프로그램 제작 표준계약서, 디지털콘텐츠 공급 표준계약서를 조항 구조 참고로만 쓴다.

| 단계 | 문서 | 핵심 항목 |
|---|---|---|
| 영업 | 서비스 소개서 | 패키지, 프로세스, 포트폴리오(권리 확인된 것만), 하지 않는 것 |
| 영업 | 제안서 | 목표·타깃, 채널 전략, 편수·일정, KPI 정의와 측정 한계, 가격 |
| 영업 | 견적서 | 편당 또는 월 리테이너, 촬영 유무, 언어판, 수정 횟수, 옵션, 공급가·부가세·합계, 유효기간, 결제 조건 |
| 계약 | 영상 제작·채널 운영 대행 계약서 | 용역 범위·납품 사양(해상도, 길이, 형식, 편수), 납기·검수 기준, 수정 한도·추가 비용, 저작권 귀속과 2차 사용 범위·기간, 음원·폰트·스톡·AI 생성물 라이선스 책임, 출연자 초상권, 계정 접근·보안, 광고 표시 책임 분담, 성과 비보장, 대금(선금·잔금, 월 정산), 해지·위약금, 손해배상 한도, 비밀유지 |
| 계약 | 비밀유지계약서(NDA) | 미공개 제품·가격·성과 자료 |
| 계약 | 채널 계정 접근·운영 위임 동의서 | 위임 계정 목록, 권한 범위(업로드·댓글·통계), 자동화 도구 사용(네이버 클립 Playwright 업로드 위험 고지 포함, 01장 6.5절), 계약 종료 시 접근 회수 |
| 착수 | 과업지시서 | 월 편수, 채널별 사양, 일정, 담당자, 승인 절차 |
| 착수 | 콘텐츠 브리프·월 기획안 | 소재, 훅, 대본 구조, 금지 표현, 참고 영상 |
| 착수 | 브랜드 가이드 확인서 | 톤, 로고·색, 금지어, 경쟁사 언급 규칙 |
| 운영 | 광고 표시 준수 체크리스트 | 대가성 표시 위치(제목·영상 내·첫 해시태그·설명 첫 줄), "[광고] ○○ 제공", AI 가상인물 표시, 건강·금융 표현 |
| 운영 | 수정·변경 요청서 | 요청 내용, 한도 내/초과, 추가 비용, 일정 영향 |
| 운영 | 검수확인서 | 월 납품 목록, 승인 기록(감사 로그 참조), 이의 기간 |
| 보고·정산 | 월간 성과 리포트 | 5장 목차 |
| 보고·정산 | 청구 내역 | 패키지 금액, 옵션, 공급가·부가세, 세금계산서 발행 정보 |
