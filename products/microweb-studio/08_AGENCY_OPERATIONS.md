# 08 웹 에이전시 운영: microweb-studio

2026-10-20 작성. 상위 전략은 `../00_AGENCY_BUNDLE_STRATEGY.md`이고, 이 문서는 **웹에이전시 라인(랜딩페이지·상세페이지·경량 MVP 웹사이트)**의 영업·상품·제작 기준이다. 영업 쇼룸 기능은 `01_PRD.md`와 `../00_MERGE_ANALYSIS.md` GROUP E를 따른다. 근거 없는 값은 "제안"이다.

## 1. 상품 (원본 리포트 기준, 제안)

| 상품 | 내용 | 가격 |
|---|---|---|
| 4단계 웹개발 패키지 | 랜딩 → 경량 MVP 웹사이트 | 50만 원 ~ 300만 원 이상 |
| 크몽 결합 상품 | 숏폼 10개 + 경량 랜딩페이지(MVP) 묶음 | 번들 전략 3장, 가격은 결정 B-1 |
| 라이선스 | A 설치형(1회 10만 원 이상 + 연 30만 원) / B 호스팅 화이트라벨 / C 표준 SaaS(RLS) | 고객 규모에 따라 선택 |

## 2. 제작 워크플로우

레퍼런스 분석(Gemini) → DESIGN.md·CLAUDE.md 작성 → Stitch AI로 페이지별 생성 → 스크린샷 QA 루프. 상세페이지형 상품은 `nomad-commerce`의 섹션 템플릿과 함께 쓴다.

## 3. 영업과 번들 연계

- 숏폼·블로그로 진입한 고객에게 성과 데이터(조회·유입·전환)를 근거로 랜딩페이지·메타광고를 업셀한다(Premium·Enterprise).
- 크몽: 패키지 단가 인상으로 방어. 당근마켓: 소액 광고 + 자체 랜딩페이지로 직접 DB 수집.
- 랜딩페이지 한 장은 "노마드 마케팅 OS" 사전예약 수집용으로도 쓴다(번들 전략 6장 린 검증 3단계).

## 4. 리스크

고객 DB 수집은 개인정보 동의가 필요하다. 플랫폼 밖 연락 유도는 숨고·크몽 약관 확인 전 하지 않는다(번들 전략 R-1).
