# 03 화면과 UX: Microweb Studio

2026-10-13 개정: AI 채팅·음성·문구 위키 화면, 디자인 시스템(3.2절), 쇼룸 3D 히어로(4.6절)를 더했다. 쇼룸 히어로는 사용자 결정(2026-10-13, 확정 결정 15)으로 기존 "휴대폰 화면" 안에서 3D 안으로 바뀌었고 변경 기록은 4.4절에 있다. 공개 청첩장(`/i/*`, 템플릿 테마)과 쇼룸은 `DESIGN_PRINCIPLES.md`를 따르고 B2B 레퍼런스(Atlassian, Primer)를 쓰지 않는다. 스튜디오(운영자 화면)만 3.2절의 디자인 시스템을 따른다.

시간은 모두 제안이며 구현 후 모션 검토에서 확정한다. reduced-motion이면 0~5단계 없이 정지 이미지와 샘플 프레임만 보인다. 기울기(DeviceOrientation) 입력은 쓰지 않는다(터치·포인터 드래그만, 제안; 쓰게 되면 HERO_3D 1.1절대로 버튼으로 권한을 요청한다).

이 장은 Microweb Studio 운영자 앱 `/studio`의 공통 셸(헤더 + 좌측 GNB)과 홈 구성을 정한다. 이 제품은 공개 화면(쇼룸 `/`·`/templates`·`/portfolio`·`/pricing`·`/simulator`·`/contact`, 하객 `/i/[slug]`, 고객 시안 `/p/[token]`, 1절 `:11-19`)이 중심이라 대상은 운영·관리 셸인 `/studio`이고, 공개 화면은 셸 밖 화면으로 둔다(8.6절). 목적은 원본 4개의 메뉴·기능이 모두 새 구조 어딘가로 이행되게 하는 것이다. premium-wedding-invitation은 관리 화면 없이 하객 섹션 7개(`docs/reviews/premium-wedding-invitation.md:27-34`)와 관리자 편집 화면·다중 커플 작업(`:103-104`)이 있고, nexus-micro-web-builder는 12개 모델 쇼케이스와 미연결 메뉴(`docs/reviews/nexus-micro-web-builder.md:29-33`), webcraft-agency-simulator는 랜딩·시뮬레이터·모킹 로그인·관리자 대시보드·견적 문의(`docs/reviews/webcraft-agency-simulator.md:29-33`), WebSite는 납품 사이트 5개(`docs/reviews/WebSite.md:12`, `:28`, `:46`, `:61`, `:77`)다. 1절 화면 표의 경로·권한·플랜은 그대로이고, 1절에는 메뉴 순서·사이드 내비 문단이 없어 이 장의 8.3절 표가 처음 정하는 GNB 정본이다. 새 경로는 만들지 않는다. 다른 제품과 `_design-guide` 공용 패턴은 바꾸지 않는다(microweb-studio 전용).

디자인 시안: Design 캔버스 "Microweb Studio 대시보드 · GNB 초안"(홈, GNB 접힘, 모바일 햄버거·서랍 + 메뉴 화면 5개: 문의, 제작 주문, 사이트, 새 사이트, 문구 위키). 시안은 라이트(백자) 테마만 그리고 시안의 수치·데이터는 모두 [예시]다.
