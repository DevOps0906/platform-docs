## 2. 사용자 플로우

### F1. 초대 → 첫 사이트 생성 → 게시(대행, 필수 플로우)

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | (메일) | 운영자가 초대 메일 링크를 연다 | Supabase Auth 초대 → `auth.users` INSERT(`signup_app='microweb'`) → 개인 조직, 엔타이틀먼트(free) | 링크 만료 → `/login`에서 재요청 |
| 2 | `/studio` | 첫 진입 | `session_context('microweb')` + `studio_access` 확인 | 허용 목록 없음 → `/pending` "초대 확인 중입니다" |
| 3 | `/studio/leads/[id]` | 문의를 연락함/견적으로 바꾼다 | `set_lead_status` | 허용되지 않은 전이 → 토스트 |
| 4 | `/studio/orders` | 주문 생성 → 입금 확인 후 "결제 확인" | `create_order` → `transition_order('paid', method, ref)` | 참조에 긴 숫자열 → "카드번호는 적지 마세요" |
| 5 | `/studio/sites/new` | 템플릿, 제목, 주소(slug), 예식일 입력 | `create_site` | slug 중복 409, 상한 MW005 |
| 6 | 편집기 | 블록 입력, 사진 업로드 | 업로드 서명 URL → 완료 라우트 → `asset.process` 잡(진행률 Realtime) | 15MB 초과 413, 형식 오류 415 |
| 7 | 편집기 | "공개 동의 받음" 체크(근거 선택) | `confirm_disclosure_consent` | - |
| 8 | 편집기 | "고객에게 시안 보내기" | `issue_preview_token` → 링크 복사, 상태 review | - |
| 9 | `/p/[token]` | 고객이 이름 입력 후 "이 시안으로 진행" | `record_customer_approval` | 만료 MW013 → "운영자에게 새 링크를 요청하세요" |
| 10 | 편집기 | "게시" | 04장 게시 라우트 → 잡 → `finalize_publish` | 주문 미결제 MW008, 고객 미승인 MW009 |
| 11 | `/i/[slug]` | 링크 공유 | 스냅샷 렌더 | 게시 실패 → 이전 상태로 복구 표시 |

### F2. 하객 열람과 방명록

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | `/i/[slug]` | 카카오 링크를 연다 | anon으로 `site_publications` 조회, 블록 렌더 | 없음/만료 → 404/410 "공개 기간이 끝났습니다" |
| 2 | 오시는 길 | 지도 앱 버튼 | 딥링크 | 앱 없음 → 웹 지도 |
| 3 | 계좌 | 복사 | 클립보드, 토스트 2초 | 권한 거부 → 번호 선택 가능 표시 |
| 4 | 방명록 | (선택) "AI로 초안 쓰기" | `api/public/greeting` | 429 → "잠시 후 다시", 실패 → 직접 입력 안내 |
| 5 | 방명록 | 이름, 글 입력 후 남기기 | 허니팟 → `submit_guestbook_entry` | `rate_limited` 429, `spam` 422, `closed` 410 |

### F3. 견적 문의(쇼룸)

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | `/simulator` | 업종, 등급 선택 → "이 조합으로 상담받기" | 쿼리로 `/contact` 프리필 | - |
| 2 | `/contact` | 연락처, 동의 체크, 제출 | `create_lead` → 운영자 메일 | 동의 없음 → 필드 오류, 429 |
| 3 | 완료 | - | "영업일 1일 안에 연락드립니다"(운영 정책 확정 전 제안 문구) | - |

### F4. 셀프 결제 → 발행(Phase 2, 결제 필수 플로우)

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | 편집기 | "게시(30 크레딧)" | 잔액 확인 | 부족 402 → `/studio/billing` |

| 3 | 편집기 | 다시 게시 | consume → request_publish → 잡 | 잡 실패 → 자동 환불, "크레딧을 돌려드렸습니다" |
