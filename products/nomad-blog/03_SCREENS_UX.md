## 2. 사용자 플로우

### 2.1 가입 → 부트스트랩 → 첫 발행

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | `/signup` | 이메일 가입 | `signUp(options.data.signup_app='blog')` → 코어 트리거가 개인 조직, free 엔타이틀먼트, 월 크레딧 20 | 이메일 미인증이면 인증 안내 화면 |
| 2 | `/dashboard` | 첫 방문 | `session_context('blog')`. 빈 상태: "첫 채널을 연결하고 원고를 만드세요" 2단계 안내 | `entitled=false`면 `bootstrap_app_for_org` 호출 후 새로고침 |
| 3 | `/channels` | 워드프레스 연결(가장 쉬운 채널) | 서버가 URL 검사 → `users/me` 검증 → 자격증명 암호화 저장 → active | 사설 IP·http는 즉시 거부, 인증 실패는 "애플리케이션 비밀번호를 확인하세요" |
| 4 | `/posts/new` | 키워드 입력 → 추천 키워드 선택 → 템플릿·분량 선택 → 생성 | 1크레딧(키워드) + 3크레딧(원고) 선차감, `blog.generate` 잡, 진행률 Realtime | 402면 부족량과 크레딧팩 버튼 |
| 5 | `/posts/[id]` | 편집, 자동 저장 | 2초 디바운스 저장, `version` 충돌 감지 | 충돌 시 최신 불러오기 안내 |
| 6 | 발행 시트 | "검사" | 규칙 사전 → LLM 판정(1크레딧) | FAIL: 수정 위치 하이라이트. WARN: 확인 체크 후 진행 |
| 7 | 발행 시트 | 채널 선택 → "지금 발행" | 한도 확인 → 발행 행 INSERT → 잡 | 409(진행 중 발행 있음), 402 `BL004`(월 한도) |
| 8 | `/posts/[id]` | 결과 확인 | 채널별 상태 칩, 발행 URL | failed: 사유와 "다시 시도". unconfirmed: "채널에서 확인해 주세요" |

### 2.3 제휴 카드와 대가성 문구

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |

### 2.4 브랜드커넥트 자동 지원

|---|---|---|---|---|
| 1 | `/brandconnect` | "네이버 계정으로 시작" | 네이버 채널 자격증명 공유로 계정 생성 | 네이버 채널 없음: 채널 연결로 이동 |

| 3 | 캠페인 탭 | "새로 찾기" | `brandconnect.scan` 잡, 결과 목록 | 로그인 필요 → 채널 재인증 |
| 4 | 캠페인 상세 | 지원 메시지 확인(선택: AI 다듬기 1크레딧) → "자동 지원" | 지원서 생성 → `brandconnect.apply` 잡 | 429(시간당 5건), failed 사유 |

## 3. 화면별 명세

### 3.1 대시보드

```
+-------------------------------------------------------------------+
| 사이드 내비 |  이번 달 발행 7/50  | 크레딧 214 | 확인 필요 2건    |
|  대시보드   +-------------------------------------------------------+
|  원고       |  다음 7일 예약 (날짜, 채널 칩, 제목)                    |
|  캘린더     |  확인 필요: 실패 1, 결과 불확실 1 (각각 행동 버튼)       |
|  채널       |  제휴 클릭 7일 (원고별 상위 5, 막대)                    |
|  제휴       |  브랜드커넥트: 선정 1, 대기 3                           |
|  브랜드커넥트|                                                        |
+-------------------------------------------------------------------+
```

데이터: `monthly_post_usage`, `credit_balances`, `post_publications`, `affiliate_links`/`affiliate_clicks`(owner/admin), `brandconnect_applications`. 크레딧 표시: 상단 잔액.

### 3.2 에디터

```
+------------------+----------------------------------+---------------------+
| 개요(H2 목록)    | 제목 입력                         | 보조 패널 탭:        |
| 드래그 정렬      | [잠금] 대가성 문구 블록           |  AI | 제휴 | 키워드 |
|                  | 본문(TipTap)                      |  SEO | 검사         |
| 원고 정보        |  - 제휴 카드(자동 삽입 표시)      |                     |
|  템플릿, 키워드  |                                   | AI: 다시쓰기 지시문  |
|  태그            |                                   |  예상 크레딧 1       |
+------------------+----------------------------------+---------------------+
| 하단 바: 자동 저장됨 14:02 · 버전 5 | 미리보기(채널 선택) | 발행        |
+------------------------------------------------------------------------+
```

목적: 원고 편집과 발행 전 확인. 데이터: `blog.posts`(콘텐츠 컬럼 직접 UPDATE), `post_affiliate_links`, `core.jobs`(생성 진행률). 크레딧 표시: AI 버튼마다 예상 크레딧. 레퍼런스: 생성 입력과 결과를 나란히(`https://dribbble.com/shots/18325015-SEO-Copywriting-AI-Tool-Web-App`), 편집기 옆 보조 패널(`https://dribbble.com/shots/22408990-Lexi-AI-Writer-Assistant-Web-App-Saas-Platform-Chat-AI`). 채팅 말풍선이 편집기를 가리지 않게 패널 폭 320px 고정.

### 3.3 발행 시트

구성: 채널 계정 체크 목록(상태, 세션 만료일, 오늘 남은 발행 수) → 검사 결과(PASS/WARN/FAIL + 항목) → 채널 정책 경고 → 즉시/예약 → "발행". 데이터: `channel_accounts`, `posts.compliance_*`. 크레딧: 검사 1.

### 3.4 캘린더

월/주 보기, 채널 색 범례(색만으로 구분하지 않고 채널 이름 칩 병기). 레퍼런스: 편집 캘린더 + 예약 위젯(`https://dribbble.com/shots/9895896-WP-Scheduled-Posts-Missed-Schedule-Best-Editorial-Calendar`).

### 3.5 채널

표: 채널, 라벨, 블로그 주소, 상태, 위험 동의, 세션 만료, 마지막 발행. 행동: 연결, 재인증, 해제(owner/admin). 네이버·티스토리 연결 버튼은 동의 전 잠금.

### 3.6 제휴

계정 연결(키 마스킹), 링크 표(상품, 원고, 클릭 7/30일), 원고별 클릭 막대. 수익 열은 제공자 리포트가 있는 경우만. 레퍼런스: 상품별 수익과 추이(`https://dribbble.com/shots/14671941-Farmhouse-Affiliate-Marketing-Dashboard`), 머천트 기능은 제외.

### 3.7 브랜드커넥트

탭: 캠페인(스캔 결과, 마감순), 지원(상태 칩: 작성/제출 중/제출됨/선정/미선정/실패), 설정(동의 상태, 고지문 버전, 철회). 크레딧: 메시지 다듬기 1.

### 3.8 설정 > 대가성 문구

제공자 4개 x `blog_top` 문구 편집. 끄는 스위치 없음. 저장 조건: 10자 이상 + 경제적 이해관계 단어 포함(01장 6.3절). 미리보기는 실제 글 상단 렌더.
