## 사용 제한 (저작권·디자인 원칙 판정 요약)

판정 근거와 전체 표는 `LANDING_PERSUASION.md` 1장이다.

| 구분 | 무엇 | 처리 |
|---|---|---|
| 쓸 수 있음 | 설득 순서(공감 → 원인 → 근거 → 해결 → 효과 → 행동), 논증형 아티클의 단계 구성, 페이지 유형 분류, 비교 카드·단계 레일·세로 타임라인·콜아웃·출처 한 줄 같은 범용 UI 패턴, 추정치 고지 태도 | 아이디어·구조라 보호 대상이 아니다. `LANDING_PERSUASION.md` 규칙으로 제품마다 다시 쓴다 |
| 쓸 수 없음 | A-RMS의 헤드라인·질문·말풍선 문구, A-RMS가 인용한 통계와 학술 인용, 특허 흐름도, 채용공고 비교 연출, 페이지 slug(`landing_*`), Lightblue4 테마 CSS, 3D 인물 일러스트·아이콘 | 표현·고유 자료·유료 테마 자산이다 |
| 키트 주의 | `NOMAD_LANDING_KIT_SPEC.md`의 역할 탭 질문(5-1절 표), Insight 3부작 제목(1장 표), 말풍선 문구(1-2절), 도입 효과 페이지의 채용공고 비교(5-8절)는 A-RMS 문구·구성을 거의 그대로 옮긴 것이다 | 제품에 그대로 쓰지 않는다. 키트의 수치(ROI 254%, 피해 통계 등)는 "예시"이며 근거가 없어 제품 문서에 옮기지 않는다 |
| 키트 비주얼 | 다크 글래스 카드, Bebas Neue 대형 히어로, 모노스페이스 숫자, 영어 대문자 아이브로, 시머 텍스트, 섹션 페이드업, KPI 카운트업 | `DESIGN_PRINCIPLES.md` 생성형 기본값 2·4·5·6·7·8·11번에 걸린다. 제품 랜딩에 쓰지 않는다. NOMAD AI Factory 브랜드 사이트에 쓸지는 이 저장소 범위 밖이며 그 사이트의 브리프에서 정한다 |

A-RMS 사이트는 자동 수집을 막아 두어 이 저장소 작업에서 직접 열어 확인하지 않았다(미확인). 원자료의 사실 주장(기술 스택, 페이지 구성)은 원자료 작성자의 확인 범위를 따른다.
