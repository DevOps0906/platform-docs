# 신비로운AI(astro-ai) SECURITY

공통 규칙 정본은 `../_platform-core/SECURITY_BASELINE.md`(1~22장). 이 문서는 이 제품의 수치와 고유 위험만 적는다. 표기: "제안"은 근거 문서에 없어 이 문서가 정한 값, "미확인"은 확인 전. 상태: **1차 초안(2026-10-23)**

사주·타로 리딩을 생성해 PDF로 제공하는 서비스라, 위험은 "생년월일시 등 민감 개인정보", "제3자(가족·지인) 정보", "결제·환불", "PDF 링크 유출"에 모인다.

## 1. 지켜야 할 자산

| 자산 | 종류 | 저장 위치 | 민감도 |
|---|---|---|---|
| 본인 및 제3자 이름·생년월일시 | 개인정보(고민감) | `*_ciphertext`(AES-256-GCM, `ASTRO_PII_KEY_V<n>`) | 높음 |
| 제3자 정보 제공 동의 기록 | 법적 증빙 | 동의 테이블(약관 버전) | 높음 |
| 리딩 본문·PDF | 콘텐츠/개인정보 | DB + Storage | 높음 |
| 결제·크레딧 | 돈 | 주문·크레딧 테이블 | 높음 |
| AI 대화·음성 | 개인정보 | `ai_messages`, 음성은 기본 미저장 | 중간 |
| PII 암호화 키 | 키 | 서버 환경변수 | 높음 |

## 2. 위협 시나리오

| # | 누가 | 무엇을 | 어떻게 | 영향 | 대응 |
|---|---|---|---|---|---|
| T1 | 공격자 | 생년월일시 대량 유출 | DB 덤프, 로그, 백업 | 고민감 개인정보 노출 | 컬럼 암호화(앱 계층), 키는 DB와 분리, 로그에 원문 금지, 백업 접근 최소화 |
| T2 | 사용자 | 제3자 정보 무단 입력 | 동의 없이 타인 정보 저장 | 법적 분쟁 | 관계가 본인이 아니면 동의 체크 + 약관 버전 저장(AS-F-004), 삭제 시 리딩·PDF·음성까지 일괄 삭제(AS-F-026) |
| T3 | 제3자 | PDF 링크 공유·유출 | 서명 URL 전달 | 리딩 열람 | 이메일은 첨부 대신 서명 URL, 다운로드 URL 발급 한도(AS-F-025), 만료 시간 짧게 |
| T4 | 공격자 | 결제·환불 악용 | 웹훅 재전송, 환불 후 크레딧 사용 | 금전 손실 | 서버 confirm + 금액 대조 + 멱등, 환불은 사유 필수 + 감사 로그, 미사용 크레딧 조정 |
| T5 | 봇 | 비회원 Live Demo 남용 | 대량 요청 | 비용·서버 부하 | IP 해시당 하루 3회(AS-F-024), 입력은 저장하지 않는지 확인 필요 |
| T6 | 사용자 | PDF 렌더 SSRF | HTML 외부 URL 참조 | 내부 접근 | WeasyPrint `url_fetcher`는 자체 Storage만(AS-F-013) |
| T7 | 관리자 오남용 | 민감 열람·크레딧 임의 지급 | 내부 계정 오용 | 신뢰 훼손 | `platform_admin`만, 모든 쓰기 감사, 크레딧 지급 사유 필수, 관리자 2단계 인증 |
| T8 | 외부 | 상용 AI에 민감 정보 전송 | 생년월일시가 프롬프트에 포함 | 국외 이전 | 국외 이전 동의, `contains_pii` 문서는 오픈소스 모델만(§16), 프롬프트에 불필요한 원문 제외 |

## 5. 이 제품에만 있는 위험

- **생년월일시는 식별 가능성이 높은 민감 정보**로 보고 암호화·삭제·국외 이전 동의를 가장 엄격히 적용한다.
- **오락·참고용 표시:** 운세 결과를 사실처럼 단정하지 않는 문구와 금지 표현(01_PRD 5장)을 지킨다.
- **미성년자:** 가족 등록 시 미성년 정보가 들어올 수 있어 법정대리인 동의 체크가 필요하다(AS-F-004).
- **탈퇴 후 보관:** 30일 purge와 백업 보존 기간이 충돌하지 않는지 확인.
