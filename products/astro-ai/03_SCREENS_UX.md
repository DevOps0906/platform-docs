## 2. 사용자 플로우

### 2.1 가입 → 부트스트랩 → 환영 크레딧

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | `/signup` | 이메일·비밀번호 또는 Google, 필수 동의 2개 + 국외 이전 동의 | `signUp(options.data.signup_app='astro')` → 가입 트리거가 프로필, 개인 조직, starter 엔타이틀먼트 생성 | 레이트 리밋 초과 429 |
| 2 | `/auth/verify` | 메일 링크 클릭 | `/auth/callback` → 세션 생성 | 링크 만료 → 재발송 버튼 |
| 3 | `/auth/callback` | - | 이메일 인증 또는 Google 확인 → `POST /api/auth/welcome` → `grant_credits(30, signup:<org>:astro)`, `consents` 3행 | 같은 IP 해시 하루 3회 초과 → 지급 보류 + 안내 |
| 4 | `/dashboard` | - | "본인 프로필을 먼저 등록하세요" 빈 상태 | - |

### 2.2 보관함 등록 → 첫 사주 리딩

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | `/dashboard/subjects/new` | 호칭, 관계, 성별, 생년월일, 생시/모름, 양·음력, 윤달, 자시 방식, 출생지 | 브라우저 엔진이 원국 프리뷰 즉시 갱신 | 음력 윤달이 없는 달 → 폼 오류 |
| 2 | 같은 화면 | (본인 아님) 제3자 동의 체크 → 저장 | `POST /api/subjects` → 암호화 저장 + 동의 기록 | 동의 없음 400, 21명째 409 |
| 3 | `/dashboard/readings/new` | 사주(15cr) 선택 → 대상 선택 → 질문(선택) → 테마 → "15크레딧으로 리포트 만들기" | `POST /api/readings` → 202 `{reading_id}` | 잔액 부족 402 → 충전 모달(필요량 표시) |
| 4 | `/dashboard/readings/[id]` | 대기 | `readings` Realtime으로 단계 표시(해석 작성 중 → 책자 만드는 중 → 완료) | 실패 → "크레딧 15를 돌려드렸습니다" + 다시 시도 |
| 5 | 같은 화면 | 웹 뷰어로 읽기, PDF 받기 | 7일 서명 URL 발급, 이메일 발송 상태 표시 | 발송 dead → 재발송 버튼 |
