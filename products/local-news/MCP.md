# 로컬뉴스 클라우드(가칭, local-news) MCP

공통 규칙 정본은 `../_platform-core/MCP_BASELINE.md`. 이 문서는 이 제품의 도구와 수치만 적는다. 표기: "제안"은 근거 문서에 없어 이 문서가 정한 값, "미확인"은 확인 전, "확인 필요"는 기존 문서에서 정확한 이름을 찾지 못한 것. 상태: **1차 초안(2026-10-23)**

## 1. 노출 목적과 대상 에이전트

이 제품에서 에이전트에게 내줄 만한 것은 **이미 공개된 기사**뿐이다. 독자 사이트의 공개 기사는 이미 anon 키로 `news.read_article`, `news.search_articles`, `news.most_read` 같은 공개 RPC를 통해 서버가 읽고 있다(`04_API.md` 1·3절, `05_DATA_MODEL.md` 4절 권한 표). 반대로 편집국 쪽 데이터(초안, 제보와 취재원, 독자 명단·연락처, 댓글 신고, 광고주, 정정 청구인)는 개인정보와 취재원 보호가 걸려 있어 도구로 열지 않는다. 기사 게시·승인·정정 게재는 사람(데스크)만 한다는 규칙(`CLAUDE.md` 2절 "사람 승인", NW006)이 있으므로 **게시·수정·승인에 해당하는 도구는 만들지 않는다.**

| 대상 | 시키는 일 | 단계 |
|---|---|---|
| 독자의 AI 비서(익명) | "OO신문에서 이번 주 시의회 기사 찾아줘", "많이 본 기사", "이 기사 요약과 정정 내용" | 1.5(신문사가 허용한 경우만, D-M1) |
| 독자의 AI 비서(익명) | "OO신문 발행인·편집인·청소년보호책임자는?", "제보하려면 어디로?" (웹 링크 안내) | 1.5 |
| 편집국 데스크/편집인의 AI 비서(로그인) | 주간 자체기사 비율 등 법정 점검 수치 읽기 | 1.5(인증 방식 확정 후) |

**신문사별 허용이 먼저다:** 신문사는 `syndication_settings.ai_crawler_policy`(allow / block_training 기본 / block_all, `05_DATA_MODEL.md` 2절 `syndication_settings`, `01_PRD.md` NW-F-045, 해당 기능은 P1)로 AI 크롤러 접근을 정한다. 에이전트의 실시간 조회가 "학습 크롤러"인지 "사용자 요청 조회"인지 법적·정책적 구분은 미확인이다. 그래서 이 문서는 (제안) **`block_all`이면 모든 기사 도구가 `AI_ACCESS_BLOCKED`로 거절하고, 허용 여부 설정이 없는 신문사는 기본 꺼짐**으로 둔다(D-M1).

**노출하지 않는 것:** 기사 작성·저장·제출·승인·게시·예약·게시 취소·정정 게재, AI 초안·교정(`/api/ai/press-draft`, `/api/ai/assist`, 크레딧 소비), 초안·검토 대기·엠바고·예약 기사, 제보(`submit_tip`, 첨부, 익명 요청, 연락처), 정정·반론 청구(`submit_correction_request`, 청구인 정보), 독자 계정·명단·내보내기, 댓글 쓰기·신고·모더레이션, 뉴스레터 구독, 푸시, 독자 결제(멤버십·후원·업소 등록), 업소 등록·경조사 접수(전화·주소 포함), 광고 운영, 구성원 초대·역할, 외부 연동(웹훅, 결제 키), 신문사 개설 승인과 운영 API(`/api/ops/*`) 전부. 독자 댓글 목록(`list_comments`)도 이용자 작성 글이라 MVP에서는 열지 않는다(이유 5절 MT1, MT5).

## 2. 도구 목록

모든 도구는 기존 공개 RPC 또는 편집국 RPC를 그대로 호출한다. 규칙(공개 판정 `article_is_live`, 프리미엄 잠금, 엠바고)은 DB가 판정한다. 신문사는 입력으로 받은 **공개 식별자(제호 슬러그 또는 도메인)** 를 서버 `resolve_tenant`로 해석해 정하며, 조직 id는 입력으로도 출력으로도 쓰지 않는다(`04_API.md` 1절 "조직 출처").

| 도구 | 등급 | 한 줄 설명 | 호출하는 RPC/서버 함수 | 출력 필드(허용 목록) | 제외 필드 | 단계 |
|---|---|---|---|---|---|---|
| `news_search_articles` | R0 | 한 신문사의 공개 기사 검색 | `news.search_articles(p_org, p_query, p_limit, p_offset)` | article_id, slug, 제목, 요약, 게시 시각, 순위, 기사 웹 링크 | 본문, 초안·예약·엠바고 기사(DB가 걸러냄), 조직 id, 작성자 id | 1.5 |
| `news_get_article` | R0 | 공개 기사 1건의 메타와 본문 발췌 | `news.read_article(p_org, p_slug)`. 프리미엄 잠금(`locked`)이면 본문 없음. 반환 jsonb의 키 이름은 확인 필요(`05_DATA_MODEL.md`에 키 목록 없음) | 제목, 부제, 요약, 섹션·지역 이름, 바이라인 이름, 게시·최종 수정 시각, 유형 라벨(자체기사·전재·보도자료·기고·기사형 광고), 광고·후원 표시, AI 고지(`ai_assisted`, `ai_disclosure`), 여론조사 표시(`poll_disclosure`), 공개 정정 메모(종류·내용·시각), 잠김 여부, **본문 발췌(1,200자, 제안; 자체기사만)**, 웹 링크 | 프리미엄 본문(잠김 시), 전재·기고·보도자료 본문(요약과 링크만, 8절 D-M3), 기자 연락처·`user_id`, 초안 이력(`article_revisions`의 공개 메모 외), 사진 원본 경로, 조직 id | 1.5 |
| `news_get_most_read` | R0 | 최근 많이 본 기사 순위 | `news.most_read(p_org, p_window, p_limit)` (`window`는 `1h`/`24h`) | 순위, article_id, slug, 제목, 웹 링크 | 조회수 값(제안: 순위만), 기사 본문 | 1.5 |
| `news_get_newspaper_info` | R0 | 신문사 필요적 게재사항과 제보·정정 청구 웹 링크 | `news.is_public_newspaper(p_org)`로 공개 여부 확인. 게재사항 읽기 경로는 확인 필요(04장에 공개 프로필 조회 RPC 없음, D-M4) | 제호, 발행인·편집인 이름, 청소년보호책임자 이름, 발행소 대표 연락처, 등록번호(법정 표기), 제보·정정 청구 폼 웹 링크(경로 03장 1.1절 기준, 확인 필요) | 등록증 파일, 신청자 이메일·전화, 구독 플랜, 결제 키, 구성원 목록·초대, 조직 id | 1.5 |
| `news_get_compliance_weekly` | R2 | 주간 자체기사 비율 등 법정 점검 수치 | `news.compliance_weekly_stats(p_org, p_week_start)` (D+, 월요일 시작 주. 조직은 세션 `org`) | 주 시작일, 게시 건수, 유형별 건수(자체·보도자료·AI 보도자료·전재·기고·기사형 광고), 자체기사 비율, 경고 플래그 | 기사 목록·제목, 기자 개인별 수치, 독자 수치 | 1.5(D-M2 이후) |

**만들지 않는 도구:** `news_create_article`·`news_update_article`·`news_submit_article`·`news_review_article`·`news_publish_article`·`news_schedule_article`·`news_unpublish_article`·`news_record_correction`(작성·승인·게시·정정 게재 — 사람 승인 규칙), `news_draft_from_press_release`·`news_ai_assist`(크레딧 소비), `news_submit_tip`·`news_list_tips`(제보·취재원), `news_submit_correction_request`·`news_list_corrections`(청구인 정보), `news_post_comment`·`news_list_comments`·`news_moderate_comment`, `news_subscribe_newsletter`, `news_list_readers`·`news_export_readers`, `news_checkout_membership`·결제 전부, `news_submit_listing`·`news_submit_life_event`, 광고·구성원·도메인·결제 설정 전부, 운영(`/api/ops/*`) 전부. 필요해지면 06장에 별도 작업으로 올리고 승인 흐름부터 설계한다. 제보와 정정 청구는 "준비(prepare)" 도구도 만들지 않는다. 글 내용과 연락처, 익명 요청을 에이전트가 거치면 제보자 보호가 약해지기 때문이다. `news_get_newspaper_info`가 웹 폼 링크만 안내한다(Turnstile·허니팟 검사가 있는 사람용 폼, `04_API.md` 1절 봇 차단).

## 3. 인증과 scope

| scope | 도구 | 비고 |
|---|---|---|
| (없음, 익명) | `news_search_articles`, `news_get_article`, `news_get_most_read`, `news_get_newspaper_info` | anon 키 + 공개 RPC. IP 레이트 리밋. 신문사별 AI 접근 허용 설정 필요(D-M1) |
| `news:newsroom:read` | `news_get_compliance_weekly` | 편집국 구성원 세션 필요. 역할은 DB(`news.assert_staff`, D+)가 판정. 편집국 호스트 로그인(`newsroom.<플랫폼>`)과 독자 로그인은 별개 |

- 독자 로그인 도구는 만들지 않는다(독자 본인 데이터 R1 도구 없음). 독자는 조직 멤버가 아니라 신문사별 `news.readers` 행이어서(`README.md` 1절) 이 문서 범위에서는 제외한다.
- 익명 도구가 쓰는 DB 클라이언트는 **anon 키 서버 클라이언트**다(`CLAUDE.md` 2절 "공개 읽기"). 로그인 도구는 사용자 본인 토큰으로 만든 요청 단위 클라이언트만 쓴다. MCP 서비스 환경에 `SUPABASE_SERVICE_ROLE_KEY`, 신문사 Toss 키(vault), `REVALIDATE_SECRET`, `AI_TOKEN_PRIVATE_KEY`, 웹훅 비밀을 두지 않는다.
- 편집국 도구의 토큰 획득 방식은 **미결정**이다(D-M2).

## 4. 제한값

| 항목 | 값 |
|---|---|
| 익명 IP 레이트 리밋 | 30회/분(제안). 키는 `news:mcp:<ip_hash>`, 원문 IP 저장 금지(`04_API.md` 1절 IP 해시 규칙) |
| 신문사별 일일 상한 | 신문사당 하루 N회(제안, 값은 미정). 한 에이전트가 한 신문사 전체를 긁어 가는 것을 막기 위함 |
| 사용자 레이트 리밋 | 편집국 도구 10회/분(제안) |
| 응답 최대 건수·문자 수 | 검색·순위 20건, 제목 100자, 요약 300자, 본문 발췌 1,200자, 정정 메모 500자, 검색어 100자(`news.search_articles`와 동일) |
| 검색 페이지 | 20쪽 이하(`04_API.md` `GET /api/r/search`와 동일) |
| 토큰 만료 | 편집국 접근 토큰 1시간 이하(제안) |
| 크레딧 소비 | 0. 도구 중 크레딧을 쓰는 것이 없다 |

## 5. 제품 고유 위협

| # | 위협 | 대응 |
|---|---|---|
| MT1 | **기사 본문·정정 메모 속 지시문**이 도구 결과로 에이전트에 들어감. 보도자료, 기고, 전재, 광고주 제공 문구는 외부 자료다(`CLAUDE.md` 7절 "기사형 광고", `05_DATA_MODEL.md` type 값). 기고·보도자료는 신문사가 검수해도 지시문이 남을 수 있음 | 본문 발췌·정정 메모·요약은 `untrusted` 표시 + 길이 제한 + 링크·HTML 제거. 쓰기·게시 도구가 없어 지시가 따라져도 신문사 상태를 바꿀 수 없음. 독자 댓글은 도구에서 제외 |
| MT2 | **저작권·AI 크롤러 정책 우회**: 신문사가 AI 접근을 막았는데(`block_all` 또는 학습 차단) 에이전트가 우회, 또는 전문을 그대로 재배포 | `ai_crawler_policy` 확인 후 `block_all`이면 거절(D-M1). 본문은 자체기사 발췌 1,200자까지, 항상 기사 웹 링크와 출처(신문사 제호)를 함께 반환. 전재·기고·사진은 계약·저작권 범위가 달라 본문을 내지 않음(D-M3) |
| MT3 | **유료(프리미엄) 본문 유출**(`05_DATA_MODEL.md` 7절 #11) | 본문 접근은 `read_article`만. 익명이므로 `locked`이면 본문 없이 요약과 잠김 표시만. 도구가 멤버십 세션을 만들지 않는다. 미터형 무료 건수는 DB가 강제하지 않는 한계가 있으므로(`04_API.md` 2.1절) 에이전트용 발췌는 미터를 소모하지 않게 별도로 정해야 함(D-M5) |
| MT4 | **미게시·엠바고·예약·게시 취소 기사 노출**(`05_DATA_MODEL.md` 7절 #2) | 공개 RPC가 `article_is_live`를 판정(초안·엠바고·예약 0행). 도구는 초안/검토 경로를 호출하지 않음. 게시 취소·정정된 기사는 최신 DB 값만 반환하고 캐시하지 않으며, 응답에 최종 수정 시각과 공개 정정 메모를 함께 줌 |
| MT5 | **제보자·취재원·청구인 보호**: 제보(익명 요청 포함), 정정 청구인 연락처, 기자 개인 연락처가 에이전트와 그 모델 제공자에게 전달됨 | 제보·정정 청구 도구와 관련 필드를 만들지 않음. 기자 `user_id`·이메일·전화는 출력 제외(바이라인 이름만). 편집국 도구는 건수만 반환 |
| MT6 | **위치 정밀도**: 지역 기사에서 업소·경조사·제보·행사의 정확한 주소, 전화가 새어 나감 | 지역은 섹션/지역 분류 이름(구·동 단위 이하의 좌표·주소 없음)만 반환. 업소 등록(`listings`)과 경조사(`life_events`)는 도구 대상이 아님 |
| MT7 | **광고·후원·AI 보조 사실 숨김**: 기사형 광고를 일반 기사처럼, AI 보도자료 초안을 자체기사처럼 요약해 전달 | 유형 라벨, 광고·후원 표시, `ai_disclosure`, `poll_disclosure`를 출력 필수 필드로 포함. 도구 설명에 "광고·AI 보조 기사는 표시를 함께 알릴 것"을 적음. 평가셋 문항 포함 |
| MT8 | **멀티테넌트 혼선**: 여러 신문사가 같은 플랫폼에 있어 에이전트 질의가 다른 신문사 기사와 섞이거나 정지·해지된 신문사 기사를 반환 | 신문사는 호출마다 공개 식별자 1개로 해석(`resolve_tenant`). 해석 실패·정지·해지는 `NW002` 계열 거절(플랫폼 브랜드로 기사를 보이지 않는다는 규칙과 같은 방향, `CLAUDE.md` "테넌트" 절). 플랫폼 전체를 가로지르는 검색 도구는 만들지 않음 |
| MT9 | **편집국 수치 도구로 타 신문사 조직 조회** | 조직 id를 입력으로 받지 않고 세션 `org`만 사용. `news.assert_staff`와 RLS가 최종 방어선. `outsider` 페르소나 회귀(`05_DATA_MODEL.md` 10절) |

## 6. 승인 흐름

해당 없음. 쓰기·준비 도구가 없다. 기사 게시, 정정 게재, 정정 청구 응답처럼 법적 기한과 책임이 걸린 일은 사람이 편집국 웹 화면에서만 한다(`CLAUDE.md` "정정 청구" 규칙).
