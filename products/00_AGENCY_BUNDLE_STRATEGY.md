## 1. 왜 "통합 번들"인가

- 숏폼·블로그·SNS·웹을 업체 4곳에 따로 맡기면 메시지 톤이 어긋나고, 소통 비용이 겹치고, 성과 데이터가 흩어진다. 대행사 쪽은 단일 서비스만 팔면 객단가가 낮고 이탈이 쉽다.
- 대표는 자체 도구(블로그 자동화, 숏폼 제작, 광고 자동화, 상품 페이지)를 이미 가지고 있어 **운영 원가가 거의 늘지 않으면서 객단가만 3~5배** 만들 수 있다는 것이 리포트의 주장이다(검증 전 가정).
- 시너지: 숏폼·블로그는 견적 저항이 낮은 **진입 상품**, 계약 후 성과 데이터(조회·유입·전환)를 근거로 랜딩페이지·메타광고를 **업셀**한다.

## 2. 홍보(영업) 채널 7개와 우선순위

| 구분 | 채널 | 성격 | 비용 | 우선순위 전략 |
|---|---|---|---|---|
| 아웃바운드 | 숨고 | 견적당 캐시 차감 | 높음 | 초기 리뷰 확보용. 이후 지정 요청 유도 프로필로 방치 |
| 아웃바운드 | 크몽 | 검색 노출 경쟁 | 중간 | 패키지 단가 인상(숏폼 10개 + 경량 랜딩 MVP 묶음)으로 방어 |
| 지역 기반 | 당근마켓 | 비즈프로필 + 소액 광고 | 낮음 | 자체 랜딩페이지로 직접 DB 수집 |
| 인바운드 | 네이버 카페 | 커뮤니티 신뢰 | 무료 | 리소스 80% 이전 대상 |
| 인바운드 | 인스타·스레드 | 콜 DM + 콘텐츠 | 무료 | 리소스 80% 이전 대상, 셀프 계정 = 포트폴리오 |
| 확장형 | 메타광고 + 유튜브 | 통합 브랜딩 | 유동적 | 4주차 이후 DB 수집·SaaS 웨이팅리스트 확보용 |

핵심 원칙: 견적비가 나가는 아웃바운드(숨고·크몽)는 초기 후기 확보용으로 제한하고, 장기적으로는 무료 인바운드(인스타·스레드·카페)로 리소스의 80% 이상을 옮긴다.

### 2.1 채널별 실행 메모

- **숨고 견적비 절감 4단계:** ① 요청서 필터링(답변이 "미정/협의"뿐인 요청, 매칭 이력 없는 계정은 패스) ② 자동 견적 끄기, 하루 2회(오전 10시·오후 4시) 사업자등록증·브랜드 링크가 있는 요청만 수동 맞춤 견적 ③ 프로필 지역·키워드 최적화(예: "[용인/강남] 숏폼대행 + 매출 랜딩페이지") ④ 채팅 리스트에 보이는 첫 2줄에 거부하기 어려운 제안 배치.
- **알림 필터링(공식 API 없음):** 숨고 매칭 알림(카톡·이메일) → Make/n8n 이메일 파서 → "쇼핑몰/브랜드/예산 100만원 이상" 키워드 포함 건만 → Slack/텔레그램으로 "A급 매칭" 알림.
- **당근마켓:** 비즈프로필·서비스 등록, 첫 문의 DM 응대 스크립트, 동네 기반 소상공인 클라이언트 공략, 소액 광고 시 자체 랜딩으로 DB 수집.
- **크몽:** 서비스 등록·카테고리·썸네일·설명 최적화, 패키지는 "숏폼 10개 + 전환용 경량 랜딩 MVP" 묶음.
- **네이버 카페:** 자영업자·소상공인·스타트업 카페에서 기술적 애로사항 해결 댓글로 자연스럽게 인바운드. 네이버 블로그와 연동.
- **인스타·스레드:** 클라이언트를 부르는 프로필·포트폴리오 피드·하이라이트, 해시태그·팔로워 탐색 리스트업, 콜 DM(거절 대처·재연락 타이밍, **인스타 DM → 카카오톡 전환 스크립트**), 스레드 글쓰기 공식 "신뢰 + 후킹 + CTA", 릴스 1개로 문의 받는 구조.
- **메타광고·유튜브:** 소액 테스트 후 클라이언트 유입, 쇼츠 + 롱폼으로 전문가 포지셔닝, 콘텐츠 1개를 인스타·유튜브·스레드에 동시 배포(재활용).

## 3. 서비스 상품과 가격 (제안, 첫 3개 고객 원가 실측 후 확정)

### 3.1 통합 번들 Tier

| Tier | 월 가격 | 구성 |
|---|---|---|
| Starter (진입형) | 490,000원 | 블로그 포스팅 8건 + 숏폼 4개(단일 채널 업로드) |
| Growth (성장형) | 990,000원 | 블로그 12건 + 숏폼 8개 + 인스타·스레드 계정 운영 |
| Premium (전환형) | 1,990,000원 | Growth 전체 + 랜딩페이지 1페이지 제작 + 메타광고 세팅·관리 |
| Enterprise (파트너형) | 3,000,000원 이상 + 성과 인센티브 | 웹사이트(경량 MVP) + 숏폼 + 블로그 + SNS + 광고 + 통합 성과 대시보드(자체 개발) |

- 기존 숏폼 단독 Tier 1~3(월 50~100만 / 150~200만 / 300만 이상)은 위 Starter~Growth에 흡수하는 구조로 재설계한 것이다. **`sceneflow/08` 2장·9.3절의 가격과 `Price_Plans` 값이 이 표와 다르므로 결정 B-1에서 정리한다.**
- "성과 인센티브"는 매출·조회수 보장이 아니다. 보장 문구 금지는 `sceneflow/08` 1장과 같다.

### 3.2 웹에이전시 패키지와 라이선스 모델

- 4단계 웹개발 패키지(50만 ~ 300만 원 이상). 크몽에서는 "숏폼 10개 + 경량 랜딩 MVP" 결합 상품으로 판다.
- 라이선스: A 설치형(1회성 10만 원 이상 + 연 30만 원) / B 호스팅 화이트라벨 / C 표준 SaaS(RLS). 고객 규모에 맞게 제안.

## 4. 운영 자동화 구조

1. **중앙 오케스트레이션:** Supabase 멀티테넌트 단일 프로젝트(스키마 분리)로 4개 라인의 고객 데이터를 통합 관리, n8n/Make는 서비스별 워커로 배치.
2. **콘텐츠 원본 재사용:** 블로그 원고 1건에서 숏폼 스크립트·인스타 캡션·스레드 포스트를 동시 파생 생성(Claude Sonnet, OpenRouter 경유) → 제작 원가 절감.
3. **기획 자동화:** Notion/Supabase에 클라이언트 정보 입력 → LLM → 후킹 멘트·스크립트 5개 버전 자동 생성.
4. **컨펌 프로세스:** 대시보드(또는 Notion 공유 페이지)로 수정요청 비동기 수집.
5. **멀티채널 업로드:** Make/n8n으로 릴스·쇼츠·틱톡 원클릭 분산 업로드(sceneflow 다채널 배포 기능과 같은 흐름).
6. **클라이언트 대시보드:** Next.js 통합 리포트(블로그 순위, 숏폼 조회수, SNS 인게이지먼트, 광고 ROAS)를 한 화면에서 제공 → 번들 해지율 감소.
7. **알림·필터링:** 숨고·크몽 등 아웃바운드 견적 알림을 필터링해 A급 리드만 영업 리소스 투입(2.1절).

## 5. SNS대행 실행 스펙 (신규, 담당 제품 없음)

- 인스타·스레드 계정 운영(월 게시 건수는 Tier로 정함), 메타광고 세팅·관리.
- 광고 자동화: 노드 시각화 + n8n 배치로 소재 파일명 파싱(`타겟명_상품명.mp4`), **광고는 PAUSED 상태로 생성해 안전장치 유지**(고객 승인 후 활성화).
- 콘텐츠 자동화 3모드: 캔버스형 / n8n 셀프호스팅 / Make 클라우드 중 고객 인프라 수준에 맞게 제공.
- 이 라인은 platform-docs에 제품 폴더가 없다. 상시 운영 기능이 필요해지면 별도 제품으로 만들지 결정 B-4에서 정한다.

## 6. 린 검증 순서와 8주 로드맵

권고: **1~2주차는 개별 서비스(숏폼·블로그)로 캐시플로우를 만들고, 3주차부터 통합 번들로 전환**하는 하이브리드. 통합 대시보드를 먼저 만들고 시작하는 것은 검증 속도를 늦추므로 권하지 않는다.

| 순서 | 단계 | 실행 내용 |
|---|---|---|
| 1 | 시장 검증 | 숨고·당근에 프로필만 등록해 문의량으로 수요 확인(개발 없이) |
| 2 | 노코드 MVP | Notion/Google Sheet로 온보딩 폼·진행 현황 관리 |
| 3 | 랜딩페이지 | 4대 서비스 통합 소개 1장으로 "노마드 마케팅 OS" 사전예약 유도 |
| 4 | 사전예약·고객 확보 | Starter 첫 계약 3건 |
| 5 | 수익성 검증 | 1건당 실투입 시간 대비 마진율 계산 → Tier 가격 재조정 |
| 6 | 정부지원사업 | 계약 3건 이상 시 예비창업패키지/DX 지원사업 지원서에 실적 근거로 활용 |
| 7 | 자동화 구축 | 썸네일 생성·포스팅 발행부터 순차 자동화 |
| 8 | 정식 개발 | 클라이언트 대시보드 Next.js 개발 |
| 9 | SaaS 확장 | 화이트라벨 라이선스로 타 에이전시에 판매 |

| 주차 | 단계 | 실행 항목 |
|---|---|---|
| 1 | 포트폴리오 확보 | 숏폼 3개 + 블로그 3건 자체 제작, 숨고·당근 프로필 세팅 |
| 2 | 진입 상품 판매 | 크몽 패키지(숏폼 + 랜딩) 등록, 네이버 카페 인바운드 글쓰기 시작 |
| 3 | 콜 아웃바운드 | 인스타·스레드 타깃 리스트업·DM, Starter 첫 계약 목표 |
| 4 | 통합 번들 제안 | 메타 소액광고(일 5천 원)로 전자책/VOD 신청 폼 DB 수집 테스트, 기존 고객에 Growth 업셀 |
| 5~6 | 운영 표준화 | Notion 온보딩·진행관리 확립, 반복 작업 자동화 착수 |
| 7~8 | SaaS 전환 준비 | 클라이언트 대시보드 MVP 설계, 정부지원사업 지원서 초안 |

## 7. 확장 전략과 신규 사업 아이디어

- **대행 → 화이트라벨 SaaS:** 1단계(0~3개월) 수동·반자동 직접 대행, 케이스 스터디·후기 확보 → 2단계(3~6개월) 통합 대시보드를 "노마드 마케팅 OS"로 상품화, 라이선스 B로 타 에이전시 판매 → 3단계(6개월~) 정부지원사업으로 개발 인건비 확보 후 라이선스 C(표준 SaaS RLS)로 전환.
- 아이디어 1: "노마드 마케팅 OS" 화이트라벨 SaaS(1인 숏폼·블로그 대행 창업자 대상).
- 아이디어 2: AI 에이전트형 "숏폼 기획 카피라이터"(업종별 후킹 멘트·스크립트 생성, LangChain + Claude API).
- 아이디어 3: 전자책 "1인 마케팅 에이전시 창업 가이드"(9,900~28,000원), 리드 마그넷 겸용.
- 아이디어 4: 정부지원사업 연계 패키지("소상공인 디지털 전환(DX) + 마케팅 자동화").
- GEO 채널화: 인스타·스레드 강의 내용을 "1인 개발자가 노코드·AI로 숏폼 대행 자동화 시스템 만든 과정"으로 연재해, 출시할 AI 숏폼 스크립트 제너레이터 SaaS의 사전예약(웨이팅리스트) 유저를 무료로 확보.

## 8. 법·약관 위험 (반드시 확인)

| # | 항목 | 내용 |
|---|---|---|
| R-1 | 외부 채널 이탈 유도 | 리포트는 첫 견적 메시지에 자체 랜딩·카카오톡 채널로 고객 DB를 빼내는 방법을 제안한다. **숨고·크몽 약관이 플랫폼 밖 거래·연락 유도를 제한할 가능성이 크다(미확인).** 약관을 확인하기 전에는 첫 메시지에 외부 링크를 넣지 않고, 계정 정지 위험을 결정 B-2로 올린다 |
| R-2 | 자동 견적·알림 파싱 | 숨고 매칭 알림 이메일 파싱은 본인 계정 알림 활용이라 위험이 낮지만, 플랫폼 화면 자동 수집(스크래핑)은 약관 확인 전 하지 않는다(`sceneflow/08` A-3과 같은 원칙) |
| R-3 | 후기·성과 표현 | "환불", "매출 보장" 같은 거부하기 어려운 제안 문구는 허위·과장 광고 소지가 있다. "영상만 만들고 매출 안 나오면 100% 환불" 같은 문장은 환불 조건을 문서로 명시할 수 있을 때만 쓴다(제안) |
| R-4 | 광고 대행 | 광고주 계정 권한 위임 동의서, 광고비 정산 구조, 광고 심의·표시광고 준수 필요. 광고는 PAUSED로 시작한다 |
| R-5 | 개인정보 | 고객 DB 수집(랜딩·전자책 신청 폼)은 수집·이용 동의 필요(`_platform-core/SECURITY_BASELINE.md`) |
| R-6 | 계정 운영 | 고객 SNS 계정 로그인 정보 보관 금지, 공식 위임 권한만 사용 |
