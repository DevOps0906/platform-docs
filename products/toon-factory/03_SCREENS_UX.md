# 03 화면과 UX: Toon Factory

작성일 2026-10-12. 원본의 UI 지침은 다크 모드(`bg-slate-950`)와 3단 레이아웃(좌측 에셋 탭, 중앙 캔버스, 우측 레이어/스타일 패널) 두 줄뿐이다(`Toon-Factory/Design.md:27-29`). 화면 목록과 플로우는 이 문서에서 새로 정한다.

## 2. 사용자 플로우

### 2.1 가입 → 부트스트랩 → 첫 생성 (필수)

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | `/signup` | 이메일·비밀번호 또는 Google, 만 14세 이상 확인 | `signUp({ options.data.signup_app: 'toon' })` → 가입 트리거가 free 구독, 엔타이틀먼트, 10크레딧 지급 | 이미 가입한 이메일 → 로그인 안내 |
| 2 | `/app/onboarding` | 템플릿 3종 중 선택 | 작품 1개 + 1화 + 컷(템플릿 문서) 생성(RLS, 사용자 세션) | 엔타이틀먼트 없음(다른 앱으로 가입한 SSO 사용자) → `bootstrap_app_for_org('toon')` 호출 후 재시도 |
| 3 | `/editor/[id]` | 말풍선 문구 수정, 표정 교체 | 자동 저장 | 저장 충돌 `TN409` → 배너 |
| 4 | 내보내기 패널 | "PNG로 내보내기" | `POST /api/exports`(kind png) → 잡 → Realtime 진행률 | 월 20건 초과 → `TN005` 안내 |
| 5 | 진행률 완료 | "다운로드" | 서명 URL 1시간 | 렌더 실패 → 재시도 버튼, 실패 사유 |

### 2.2 이야기 → AI 콘티 → 조립

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | 회차 목록 | "새 회차" | 회차 생성 | 무료 3회차 초과 → `TN001` 업그레이드 안내 |
| 2 | 콘티 | 시놉시스, 컷 수, 톤, 등장 캐릭터 선택. 버튼에 "3크레딧" 표시 | `POST /api/storyboard` → 3크레딧 선차감 → 잡 | 잔액 부족 402 → 부족량 + 크레딧팩 |
| 3 | 콘티 | 결과 표 확인(컷별 장면, 캐릭터, 대사), 컷 단위 수정 | `episodes.script` 저장 | 잡 실패 → 자동 환불 표시 |
| 4 | 콘티 | "콘티 적용" | `scriptToDocs`로 컷 생성(사용자 세션, 한도 트리거 적용) | 컷 한도 초과 → 앞쪽 N컷만 적용 여부 확인 |
| 5 | 에디터 | 배경 자리 "AI 배경 만들기"(장면 설명 미리 채움) | `POST /api/generations` 4크레딧/장 | 규칙 검사 FAIL `TN006` → 수정 안내 |

### 2.3 Pro 결제 (필수)

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | `/app/billing` 또는 잠금 에셋 안내 | "Pro 14,900원/월 시작" | `POST /api/billing/checkout`(subscription) → 주문 저장 → Toss 빌링키 발급창(customerKey `org_<org_id>`) | 창 닫음 → 주문 1시간 뒤 만료 |
| 2 | `/app/billing/success` | - | `POST /api/billing/billing-key`(authKey) → 빌링키 암호화 저장 → 첫 청구 → `confirm_payment_order` → 구독·엔타이틀먼트 pro, 300크레딧 | 금액 불일치 `PM001` → "결제 확인 실패" + 운영 알림 + 승인 취소(주문 failed 기록은 별도 호출 `fail_payment_order`, 05장 6절) |
| 3 | 에디터 복귀 | - | 세션 갱신, 워터마크 해제·Pro 에셋 잠금 해제 | - |

### 2.4 MP4 내보내기

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | 내보내기 패널 | MP4 선택, 컷별 시간 확인(합계 표시), BGM, 전환, "3크레딧" | 합계 60초 이하 검사(클라이언트 보조) | 60초 초과 → `TN004` |
| 2 | 같은 화면 | "MP4로 내보내기" | 서버: 플랜(`export`에 mp4), 에셋 등급 재확인, 3크레딧, `exports` 행, 잡 | free → 403 `TN002` 업그레이드 |
| 3 | 진행률 | 대기(취소 가능: 대기 중일 때만) | 워커: 컷 PNG 렌더 → FFmpeg → `exports` 버킷 | 실패 → 자동 환불 표시 |

## 3. 화면별 명세

### 3.1 에디터 `/editor/[episodeId]`

목적: 컷을 조립한다. 원본의 3단 레이아웃(`Toon-Factory/Design.md:29`)을 유지한다.

```
+--------------------------------------------------------------------------+
| < 작품명 / 3화      저장됨 2초 전      Undo Redo   잔액 286   [내보내기]   |
+------------+-------------------------------------------+-----------------+
| 캐릭터     |                                           | 선택: 미나       |
| 배경       |        [ 컷 캔버스 1080x1350 축소 ]         | 포즈 [손흔들기v] |
| 말풍선     |                                           | 표정 6종 썸네일  |
| 효과 글자  |                                           | 반전 / 불투명도  |
| 내 에셋    |                                           | 레이어 목록      |
| (썸네일 그리드, Pro 자물쇠)                             | (드래그 순서)    |
+------------+-------------------------------------------+-----------------+
| 컷 스트립: [1][2][3*][4] [+컷]   컷 시간 2.5초                           |
+--------------------------------------------------------------------------+
```

| 항목 | 내용 |
|---|---|
| 데이터 | `toon.cuts`(RLS), `toon.catalog_assets` 뷰, `toon.user_assets`, `core.credit_balances`, 서명 URL(`/api/catalog/sign`) |
| 행동 | 배치, 변형, 표정 교체, 말풍선 편집, AI 배경, 대사 다듬기(1크레딧), 컷 추가/정렬 |
| 크레딧 표시 | 상단 잔액. AI 버튼마다 단가 표시 |
| viewer | 캔버스 잠금, 내보내기 버튼 숨김(서버도 거부) |

원칙: (1) 실제 결과물(샘플 회차)이 히어로다. (2) 크롬은 펜선 남색 한 가지로 조용히. (3) 노랑은 행동 하나(시작)에만. (4) 모션은 스트립 스크롤에 따른 주석 전환 하나뿐(`prefers-reduced-motion`이면 정적 목록). (5) 카피는 하는 일을 평이하게.

대담함의 위치: 히어로의 세로 스트립. 스크롤하면 오른쪽 주석이 지금 보이는 컷의 재료(포즈, 표정, AI 배경 여부)로 바뀐다.
