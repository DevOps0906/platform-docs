# 08 BENCHMARK: Toon Factory 경쟁 도구 비교와 보강안

작성일 2026-10-13(확정 결정 20). 이 문서는 AI 웹툰·인스타툰·숏툰 도구를 같은 기준으로 비교하고, Toon Factory에 없는 기능을 기획 보강안(01_PRD 반영 항목)으로 바꾼다. 셀의 내용은 각 서비스의 공개 소개 페이지나 제3자 정리 글에서 확인한 것만 적고, 출처가 없는 칸은 "미확인"으로 둔다. 제작사 자체 소개 문구는 실제 성능을 보증하지 않으므로 3장의 직접 사용 점검으로 다시 확인한다.

### 1.3 읽는 법

- TF는 **캐릭터 일관성을 생성이 아니라 조립으로 해결**한다. 경쟁 도구 대부분은 생성 + 학습(커스텀 캐릭터)으로 일관성을 맞춘다 [S6][S7][S8]. 그래서 TF는 그림 실력 없는 사용자에게 예측 가능한 결과를 주지만, 자기 캐릭터를 만들고 싶은 사용자는 놓친다. 이 차이는 D2(캐릭터 시트)의 우선순위 근거다.
- 기획 단계(로그라인·시놉시스)와 숏폼 변환(자막·모션)은 경쟁 도구가 앞서 있고 TF가 비어 있는 구간이다 [S3][S4][S5].
- 브랜디드 툰은 비교 대상 어디에서도 기능으로 확인되지 않았다. 마케터 페르소나(도윤)와 쇼츠·툰 대행 운영(shortsflow `08_AGENCY_OPERATIONS.md`)에 맞는 **차별화 후보**다.

### 3.3 점수 기준

12개 항목을 0~3점으로 매긴다. 0 = 없음, 1 = 있으나 수동 작업이 많음, 2 = 실사용 가능, 3 = 경쟁 우위. 항목별 가중치(합 100)는 페르소나 과제 기준으로 정한다.

| 항목 | 가중치 |
|---|---|
| 캐릭터 일관성 | 15 |
| 콘티 | 12 |
| 숏폼 변환 | 12 |
| 포맷 프리셋 | 10 |
| 말풍선·레이아웃 | 10 |
| 로그라인·시놉시스 | 8 |
| 상업 이용·워터마크 | 8 |
| 가격 | 8 |
| 직접 업로드 | 7 |
| 브랜디드·B2B | 5 |
| 배경 | 3 |
| 리더 앱 | 2 |

- 총점은 (점수 / 3 x 가중치)의 합이다.
- TF가 1위가 아닌 항목 중 가중치 10 이상은 다음 분기 P1 후보로 올린다.
- 점수는 3.2절 직접 사용 결과로만 매긴다. 소개 페이지만 보고 2점 이상을 주지 않는다.

### 3.4 출처 규칙

- 셀마다 출처 번호 [S#]를 단다.
- 제작사 소개, 제3자 정리 글, 직접 사용을 구분한다. 직접 사용은 [U-YYYY-QN]으로 표기한다.
- 가격·규격은 바뀌기 쉬우므로 확인일이 두 분기 이상 지난 셀은 "재확인 필요"로 바꾼다.
- 경쟁사 상표와 화면은 이 문서와 내부 자료에서만 쓴다. 랜딩·광고 카피에 비교 문구를 쓰지 않는다(01_PRD 6.5절).
