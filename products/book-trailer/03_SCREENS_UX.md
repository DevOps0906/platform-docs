# 03 화면과 UX: NOMAD Book Trailer (book-trailer)

작성일 2026-10-15. 디자인 토큰·컴포넌트·영상 규격은 `08_DESIGN_SYSTEM.md`, 화면 구조 패턴 코드는 `docs/design-module/_design-guide/DASHBOARD_PATTERNS.md`(A~O)를 따른다. 사용자 노출 문구는 한국어, 카피는 01장 6.5절 금지 문구와 `DESIGN_PRINCIPLES.md` 카피 규칙을 통과해야 한다.

### 3.6 `/trailers/[id]/renders` (N + M)

`RenderMonitorRow` 목록: 포맷 썸네일, 해상도, 상태 점(색 + 아이콘 + 글자), 진행률(프레임 비율), 소요 시간, 크레딧, 만료일, 내려받기(영상·포스터·SRT·ZIP), 같은 스냅샷 다시 렌더, 스냅샷 보기(읽기 전용 스토리보드). 실패 행은 원인 한 줄("에셋 파일을 찾지 못함") + 원문 로그 펼치기 + 환불 표시.

### 3.7 `/trailers/[id]/publish`

플랫폼 탭(쇼츠, 유튜브, 인스타, 틱톡, 네이버 클립, 서점, 일반). 각 탭: 제목(글자 수), 설명(대가성 문구가 있으면 첫 줄 잠금 표시), 해시태그 칩, 포함 링크(단축 링크 + 태그 미리보기), 복사 버튼, ZIP. P1: YouTube 업로드(채널, 공개 범위, 예약, 합성 콘텐츠 표시 안내, 변주 부족 경고).

## 8. 대시보드 셸과 좌측 GNB (2026-10-19 추가, 원본 프로젝트 메뉴 이행)

### 8.6 홈 구성 (`/home`, 1절 홈 행 구체화)

위에서 아래 순서. 1절 홈 행 "최근 작업물 + '새 책' 주 행동", 패턴 "M + 최근 목록(`DASHBOARD_PATTERNS.md` 5장 '만드는 도구')"(:17)과 3.1절 와이어프레임(:121-136)을 따르고, 맨 위에 "오늘 처리할 일"을 더한다(제안). 주인공은 만들던 트레일러다(3.1절 목적 "만들던 트레일러를 이어서 하거나 새 책을 시작한다"). 큰 숫자 KPI 카드와 크레딧 잔액 칸을 두지 않는다(3.1절 :138 "크레딧 표시 없음(조회만)". 랜딩 원칙 4.3절 :279 "숫자 통계 없음"을 홈에도 적용, 제안). 잔액은 헤더에만 있다.

| 순서 | 영역 | 내용 | 누르면 |
|---|---|---|---|
| 1 | 오늘 처리할 일 | 검사 확인 필요(compliance WARN·FAIL, 5절 :342), 원고와 다른 인용(:341), 실패한 작업(환불 완료, :344), 7일 안에 만료되는 렌더(TR-F-054), 권리 확인 전 책(:339). 각 개수, 0이면 칩을 숨긴다 | 트레일러 목록(필터 적용), 해당 장면, 렌더 기록, 렌더 기록, 책 상세 |
