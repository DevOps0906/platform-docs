# 03 화면과 UX: Stock Dashboard

작성일 2026-10-12. 원본의 화면 지침(다크 테마, 증권사/Total 탭, 블링크, 블러 모달, 우측 AI 패널)은 구체적이므로 구조를 유지하고(`docs/reviews/Stock_Trader_nomad.md:21`), 색과 서체는 `_design-guide` 절차로 다시 정한다. 공개 랜딩은 법률 검토 후로 미루고(`docs/products/_design-guide/REFERENCES.md:207`), MVP는 초대 전용 안내 페이지만 둔다.

## 2. 사용자 플로우

### 2.1 초대 → 가입 → 부트스트랩 → 첫 연결 → 첫 진단 (필수)

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | 메일 | 초대 링크 클릭 | - | 만료 → `/invite/...`에서 "초대가 만료되었습니다. 운영자에게 재발급을 요청하세요" |
| 2 | `/invite/[token]` | 초대받은 이메일로 가입(또는 로그인) | `signUp(options.data.signup_app='stock')` → 코어 가입 트리거가 프로필, 개인 조직, default 엔타이틀먼트 생성 | 다른 이메일 → `ST031` "초대받은 이메일로 로그인하세요" |
| 3 | 같은 화면 | 자동 진행 | `POST /api/beta/redeem` → `redeem_beta_invite` → 플랜 beta 전환 → 첫 달 300 크레딧 | 이미 사용된 초대 `ST030` |
| 4 | `/onboarding/disclaimer` | 고지 읽고 두 항목 동의 | `record_consent` 2회 | 거부 → 로그아웃 안내 |
| 5 | `/dashboard`(빈 상태) | "모의투자 계좌 연결" 또는 "샘플 데이터로 둘러보기" | 샘플은 `mock` 연결 생성 + `stock.sync` | - |
| 6 | `/settings/connections` | 증권사, 앱키, 시크릿, 계좌번호 입력. "본인 계좌", "약관 위험" 체크 | `POST /api/connections` → verify → 암호화 저장 → `active` → 동기화 enqueue | 키 오류 → 행 `error` + 원인 |
| 7 | `/dashboard` | 보유 그리드 확인 | Realtime(`holdings`)로 첫 동기화 반영, SSE 시세 구독 | 시세 연결 실패 → "시세 꺼짐" 배지, 스냅샷은 보임 |
| 8 | `/ai` | "내 포트폴리오 진단하기(10 크레딧)" | 선차감 → 스트리밍 → 저장 | 크레딧 부족 402, 실패 시 자동 환불 표시 |

### 2.5 모의주문과 킬 스위치(Phase 3)

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | `/orders` 패널 | 종목, 매수/매도, 수량, 지정가 입력 | `POST /api/orders/preview` → `create_paper_order` | 한도 위반 → `blocked` 사유 표시 |
| 2 | 확인 화면(60초 카운트다운) | 수량·가격·예상 금액·현재가 대비 괴리 확인 후 "모의주문 확인" | `POST /api/orders/{id}/confirm` → `confirm_paper_order` → `stock.order_submit` enqueue | 60초 초과 → `expired` |
| 3 | `/orders` | 상태 확인 | Realtime `order_requests` | 증권사 거부 → `rejected` |
| 4 | 어디서나 상단 | "모든 주문 멈춤" | `engage_kill_switch` → 대기 주문 `blocked` | - |

### 3.4 `/settings/connections`

| 항목 | 내용 |
|---|---|
| 구성 | 연결 카드(증권사, 모의/실전 배지, 마스킹 계좌, 상태, 마지막 동기화), 추가 폼, 해제 버튼(확인 대화상자) |
| 입력 | 증권사 선택, app key, app secret(입력 후 다시 보여 주지 않음), 계좌번호(전송 후 마스킹 값만 표시), 동의 체크 2개 |
| 데이터 | `broker_connections`, `credential_summaries` |

### 3.5 `/trades`

필터 바(기간, 종목, 매수/매도), 표(체결 시각 KST, 종목, 구분, 수량, 가격, 금액, 수수료, 세금, 메모 아이콘), 메모 사이드 패널, CSV 버튼.

### 3.6 `/admin/beta`, `/admin/ops`

초대 표(이메일, 상태, 만료, 발급자), 발급 폼(이메일, 메모), 링크 1회 표시 대화상자, 회수. ops는 동기화 실패 연결 목록, 전역 킬 스위치 토글(사유 필수).
