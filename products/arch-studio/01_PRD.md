# 01 PRD: Arch Studio (가칭)

작성일 2026-10-14. 기획 초안. 이 문서의 요금·라이선스(4장)와 열린 결정(8장)은 사용자 결정(2026-10-14: 시리얼 구매로 영구 소유, AI 렌더·모델 사용은 크레딧, 진입용 구독 검토)을 반영한 정본 초안이고, 나머지 장은 02~07 작성 때 세부를 채운다. 모든 금액·크레딧·수치는 제안이다(이유: 신규 제품이라 원가 측정 전이고 확정 결정 8이 이 제품의 플랜 정본을 지정하지 않았다, `docs/products/00_MERGE_ANALYSIS.md:16`). 외부 사실은 확인일 2026-10-14 기준이며 원문 확인 전 항목은 "미확인"으로 적는다.

## 1. 페르소나와 핵심 과제

## 4. 요금과 크레딧

판매 구조는 세 층이다. (1) 앱 본체는 시리얼 번호로 영구 소유한다. (2) 법규·기능 업데이트는 연간 업데이트 플랜으로 받는다. (3) 비용이 드는 AI 작업은 크레딧으로 낸다. 초기 비용이 부담인 사용자를 위해 월 구독을 함께 둔다. 사용자가 AI 비용을 직접 해결하는 방식(사용자 키)은 기본 경로로 두지 않는다. 이유: 타깃 사용자에게 API 키 발급은 진입장벽이 높고, 법규 검토는 법령 DB가 있는 서버에서만 동작하며, 서버 크레딧에 묶인 기능은 복제판에서 쓸 수 없어 영구 라이선스의 복제 위험을 줄인다. 사용자 키는 Phase 2 선택 기능으로만 검토한다(D-10).

크레딧 표준가는 1크레딧 = 100원(부가세 포함, `pack_100` 기준)이다. 사용자에게는 토큰이 아니라 작업 단위 크레딧을 보여 준다. 실행 전에 차감 크레딧을 확정해 보여 주기 위해서다(`docs/products/nomad-docs/01_PRD.md:399`와 같은 원칙). 가격은 부가세 포함 표시(D-6)다.

### 8.2 인증 단계 결정 (2026-10-14, 확정 결정 22)

정본은 `docs/products/_platform-core/AUTH_ROADMAP.md`다. 이 제품은 공개 가입(`signup_policy='open'`)이고 8장 매트릭스에서 B = Google + 이메일, C1 카카오 P2 선택, C2 네이버 P2 선택이다(`AUTH_ROADMAP.md:338`). 다른 제품과 달리 사용자가 웹이 아니라 설치형 데스크톱 앱(Tauri)에서 로그인하므로 앱 복귀 방식(D-15)과 시리얼·계정 연결(D-16)을 함께 정한다. 사전예약 판매(D-2)는 실제 결제이므로 Stage B가 켜진 뒤에 연다. 이 제품에는 기존 카카오 열린 결정이 없다.

| D-15 | 데스크톱 앱 로그인 방식 | (a) 앱이 Supabase PKCE를 직접 시작하고 시스템 브라우저를 연 뒤 커스텀 스킴 딥링크(예: `archstudio://auth/callback`)로 `code`를 받아 `exchangeCodeForSession` (b) (a)와 같되 루프백(`http://127.0.0.1:<임의 포트>/callback`)으로 받는다 (c) 시스템 브라우저로 웹 `/login`을 열어 웹 세션을 만든 뒤 일회용 교환 코드(60초, PKCE 챌린지 묶음)를 딥링크로 앱에 넘기고 앱이 서버에서 세션으로 바꾼다 (d) 앱 안 웹뷰에서 OAuth | (a), 딥링크 등록이 막히는 환경의 대체로 (b). 이메일 로그인은 앱 안 폼에서 `signInWithPassword`로 하고 브라우저를 거치지 않는다.
