## 2. 사용자 플로우

### 2.1 가입 → 첫 생성

| 단계 | 화면 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|---|
| 1 | `/signup` | 이메일/비밀번호 또는 Google, 만 14세 이상 체크 | `signUp({options:{data:{signup_app:'notes'}}})`. 개인 조직, 월 30 크레딧 부트스트랩 | 이미 가입: 로그인 안내. 체크 누락: 가입 불가 |
| 2 | `/verify` | 메일의 링크 클릭 | 인증 완료 후 `/app` | 미인증이면 `/app`은 보이되 실행 버튼에 "이메일 인증 후 사용할 수 있습니다" |
| 3 | `/app` | 날짜 확인, 원문 붙여넣기 | 초안을 localStorage에 300ms 디바운스 저장(실패해도 동작) | 5,000자 초과: 버튼 비활성 + 초과 글자 수 |
| 4 | `/app` | 첫 실행 시 동의 모달에서 동의(원문이 외부 AI 사업자로 전송됨) | `write_audit('notes_consent.llm')` | 거부: 실행 불가 |
| 5 | `/app` | [정리하기] 또는 Ctrl+Enter | `POST /api/notes/runs` → 크레딧 선차감, 잡 생성 | 402 크레딧 부족, 409 이미 실행 중, 429 한도 |
| 6 | `/app` | 카드 A, B가 로딩 → 결과 표시, 통합 카드 로딩 → 결과 | Realtime으로 `run_steps` 반영 | 카드별 오류 표시, 환불 안내 |
| 7 | `/app` | [TXT 다운로드], [복사] | 브라우저에서 파일 생성 | |

### 2.2 카드 재요청

| 단계 | 사용자 행동 | 시스템 동작 | 실패 분기 |
|---|---|---|---|
| 1 | 실패한 카드의 [다시 요청] | `POST /api/notes/runs/{id}/retry {roles:['base2']}` | 다른 실행 중이면 409 |
| 2 | 대기 | 부모 결과 재사용(0 크레딧) + 해당 카드와 통합만 호출 | 다시 실패: 그 카드만 오류, 환불 표시 |

### 2.3 크레딧 부족 → 구매 (Phase 2)

| 단계 | 화면 | 동작 | 실패 분기 |
|---|---|---|---|
| 1 | `/app` | 실행 전 예상 크레딧 > 잔액이면 버튼 옆 "N 크레딧이 부족합니다. 크레딧팩을 구매하면 바로 이어서 정리합니다" | |
| 2 | `/app/billing` | 팩 선택 → Toss 결제창 | 결제 취소: 화면 복귀 |
| 3 | 성공 URL | 서버 confirm → 잔액 증가 | 금액 불일치: 지급 없음 + 오류 안내 |

### 2.4 보관함, 삭제, 내보내기

| 단계 | 화면 | 동작 |
|---|---|---|
| 1 | `/app/history` | 날짜 역순 목록, 날짜 범위/키워드 검색 |
| 2 | 상세 | 카드 3장 복원, TXT/복사, 삭제(휴지통) |
| 3 | 휴지통 탭 | 복원 또는 영구 삭제. 30일 후 자동 삭제 |
| 4 | `/app/settings` | 전체 JSON 내보내기, 계정 삭제 요청(30일 유예, 재로그인으로 취소) |

## 3. 화면별 명세

### 3.1 `/app` 작업실

목적: 원문을 넣고 결과 3장을 보는 하나의 일. 데이터: `notes.entries`, `runs`, `run_steps`(Realtime), `credit_balances`, `model_catalog`.

```
+------------------------------------------------------------+
| 학습 일지 정리기          잔액 26 크레딧  [보관함][설정][테마] |
+------------------------------------------------------------+
| [무료 모델을 선택했습니다. 품질이 낮거나 느릴 수 있습니다.]    |  <- 무료 모델 선택 시에만
| 날짜 [2026-05-28]                                           |
| +--------------------------------------------------------+ |
| | 오늘 수업/회의 내용을 붙여넣으세요                        | |
| |                                              2,314/5,000 | |
| +--------------------------------------------------------+ |
|            예상 4 크레딧          [정리하기  Ctrl+Enter]      |
+------------------------------------------------------------+
| 기본 A: Gemini 3 Flash   | 기본 B: DeepSeek V4 Flash        |
| 1.8초 · 412토큰 [복사][TXT][다시 요청] | 오류: 요청이 너무 많습니다 [다시 요청] |
+------------------------------------------------------------+
| 통합: Claude Sonnet 4.6  (두 결과를 모두 받으면 시작)          |
| ### 5월 28일(목) ...        [복사][TXT 260528_데이터분석_UXUI.txt] |
| AI가 생성한 결과입니다. 제출 전에 내용을 확인하세요.            |
+------------------------------------------------------------+
```

| 요소 | 동작 |
|---|---|
| 정리하기 | 실행 중 비활성(라벨 "정리 중..." + 스피너), `request_id` UUID 발급. [취소] 버튼이 옆에 나타남 |
| 모델 요약 | 카드 머리에 모델명, 공급사 배지, 응답 시간, 토큰. 재사용 카드는 "이전 결과 사용" 표시 |
| 레이아웃 | 데스크톱 1024px 이상: 기본 A, B 2열 + 통합 하단 전체 폭. 768px 이상: 2열. 미만: 1열(원본 PRD 13장. 리뷰 #12의 `md`/`lg` 중복 제거) |
| 카드 등장 | 0.1초 간격 순차 페이드(원본 PRD 15장). 사용자 행동 응답 모션만(연출 모션 최소) |

### 3.2 `/app/settings`

| 항목 | 내용 |
|---|---|
| 모델 3종 | 드롭다운. optgroup: 가벼움/표준/고급, 무료 모델 옆 주의 아이콘 + 툴팁("무료 모델은 품질이 낮거나 응답이 느릴 수 있습니다"). 플랜 비허용 등급은 비활성 + "Pro에서 사용" 표시 |
| 상태 동기화 | 패널을 열 때마다 서버 저장값으로 draft 초기화, 취소하면 버린다(리뷰 #4). 테마는 즉시 저장되고 모델 저장과 독립 |
| 데이터 | JSON 내보내기, 계정 삭제 |
| API Key 입력란 | 없음 |

### 3.3 `/app/history`

목록 행: 날짜, 키워드 2개, 상태(정리 완료/미완료), 사용 모델. 검색: 날짜 범위와 키워드(`keywords` 배열 포함, 본문 전문 검색은 Phase 2). 항목 클릭 시 상세로 이동해 결과 카드 복원.

### 3.4 `/app/billing` (Phase 2)

잔액(plan/pack 구분 표시), 최근 사용 내역(원장 `reason='notes.organize'` 요약), 플랜 카드(Free/Pro), 크레딧팩. 결제는 코어 Toss 모듈.

## 5. 상태, 오류, 빈 화면

| 상황 | 표시 |
|---|---|
| 진행 중 | 카드별 스피너, 버튼 "정리 중...", [취소] |
| 크레딧 부족(402) | "크레딧이 N 부족합니다. 크레딧팩을 구매하면 바로 이어서 정리합니다."(Phase 2 전: "다음 달 지급일 yyyy-mm-dd에 30 크레딧이 지급됩니다") |
| 플랜 부족(NT004) | "선택한 모델은 Pro에서 사용할 수 있습니다. 가벼움 또는 표준 모델을 선택하세요" |
| 이미 실행 중(NT002) | "이 일지는 정리 중입니다. 끝나면 다시 요청하세요" |
| 일일 상한(NT005) | "오늘 사용량이 가득 찼습니다. 내일 다시 시도하세요" |
| 카드 오류 | 원인 한 문장 + [다시 요청] + "이 카드의 크레딧 N은 환불되었습니다" |
| 형식 오류(`bad_format`) | "결과 형식이 맞지 않아 환불했습니다. 다시 요청하세요" |
| 네트워크 | "네트워크 연결을 확인하세요."(원본 PRD 14장 유지) |
| 저장소 용량 초과 | 초안 캐시 실패는 조용히 무시하고 서버 저장으로 진행(리뷰 #6) |
| 보관함 비어 있음 | "아직 정리한 일지가 없습니다. 첫 원문을 붙여넣어 보세요" + 작업실 링크 |
| 휴지통 비어 있음 | "삭제한 일지가 없습니다" |

## 6. 접근성과 반응형

| 항목 | 기준 |
|---|---|
| 키보드 | Ctrl+Enter 실행, Tab 순서 입력 → 정리하기 → 카드 버튼, `:focus-visible` 표시, 설정 패널은 포커스 트랩과 Esc 닫기 |
| 대비 | 본문 4.5:1 이상(라이트/다크). 형광노랑은 배경 용도로만 쓰고 글자는 먹청 |
| 스크린 리더 | 진행 상태 영역 `aria-live="polite"`, 카드에 모델명과 상태를 텍스트로 |
| 모션 | `prefers-reduced-motion`이면 형광펜 연출과 카드 페이드 제거 |
| 폭 | 375/768/1024/1440px, 가로 스크롤 없음 |
