## 3. 화면별 명세

화면의 구성·데이터·API는 1장 표가 정본이다. 여기에는 표에 담기지 않는 것만 둔다.

### 3.1 S-06 Wizard

목적: 7단계를 한 흐름으로 입력하고 언제든 이전 단계를 고친다.

```
+--------------------------------------------------------------+
| 프로젝트명 v3                             [저장됨 14:02] [AI 제안] |
+--------------------------------------------------------------+
| (1)고객 (2)가치 (3)가격 [4]경제성 (5)파트 (6)검증 (7)평가       |
+--------------------------------------------------------------+
| 월 매출*  [        ] KRW   변동비*  [        ]  이탈률* [ ] %   |
| 고정비*   [        ]                                          |
| 계산 가능 상태: 충족 / 미충족(누락: 이탈률)                      |
+--------------------------------------------------------------+
| [이전]                                              [다음]    |
+--------------------------------------------------------------+
```

| 요소 | 동작 |
|---|---|
| 단계 상태 | draft / in_progress / completed / needs_review를 아이콘 + 텍스트로 표시 |
| 자동 저장 | 입력 중 디바운스 저장, 마지막 저장 시각 표시, 실패 시 입력 보존 |
| AI 제안 | suggested 값은 별도 칸에 "AI 제안" 표시, 승인 전에는 입력값에 반영하지 않음 |
| 크레딧 표시 | [AI 제안] 옆에 예상 크레딧과 잔여(Free·Starter는 비활성 + "Pro에서 사용") |

### 3.2 S-05 대시보드와 시각화 적용

`원본 §9`와 부록 C 기준. Mermaid 문자열이 아니라 정규화 데이터를 정본으로 Diagram Engine이 코드를 생성하고 Recharts·React Flow·PDF가 같은 데이터를 쓴다.

| 영역 | 시각화 | 우선순위 | 도구 |
|---|---|---|---|
| 사업모델 개요 | Flowchart, Mindmap | P0 | Mermaid(React Flow는 인터랙티브) |
| 경제성 | XY Chart, Waterfall | P0 | Recharts(Waterfall) |
| 평가 | Bar, Radar, Quadrant | P0 | Recharts, Mermaid |
| 수익 구조 | Sankey, Pie | P1 | Mermaid |
| 시장 검증 | Funnel, Timeline | P1 | Recharts(Funnel) |
| 개발 계획 | Gantt, Kanban | P1 | Mermaid |
| 시스템 | ERD, Sequence | 내부 관리자 | Mermaid |
| AI 전략 | Decision Tree, Mindmap | P2 | Mermaid |


### 3.3 S-07 경제성 분석

- 결과마다 공식·가정 목록·경고(예: "LTV는 이탈률 일정 가정", "고객 수명 미검증")를 접이식 영역으로 표시한다.
- 실제 CAC와 허용 CAC 상한은 서로 다른 카드로 분리해 표시한다.
- 예측값과 실측값은 라벨로 구분한다.

### 3.4 S-08 증거 서랍(Evidence Drawer)

증거 등급 A 실결제·계약·사용 로그 / B 고객 행동·사전예약 / C 인터뷰·설문 / D 경쟁사·시장조사 / E AI 추정·창업자 가정(미검증). 등급은 배지(아이콘 + 글자)로 표시하고 E는 점수 근거에서 경고한다.

### 3.5 AI 화면

|---|---|---|---|
| S-11 AI 분석 | 제안 목록(Problem·Pricing·Cost·Validation·Score 분석별), 상태 배지(suggested/승인/거절), 근거·출처 | 요청, 승인, 거절 | 요청 전 예상 크레딧, 소진 시 402 `CR001` 안내 |
| 진행 표시 | 작업 상태(대기·진행·완료·실패) | 취소, 재시도 | 실패 시 크레딧 처리 안내(차감 정책은 04장 확정) |
