# BM-Core (bm-core)

## 1. 한 줄 정의

창업 아이디어를 수익모델, 단위경제, 검증 실험, 사업성 점수, 사업계획서용 구조화 데이터로 바꾸고 그 경제성과 검증 수준을 지속 관리하는 BM(사업모델) 설계 SaaS다. "AI 사업계획서 생성기"가 아니라 결정론적 계산 엔진과 증거 기반 스코어카드가 중심이다. 대상 사용자: 1순위 예비창업자·1인 창업자, 2순위 창업 컨설턴트·액셀러레이터, 3순위 창업지원기관·교육기관(`01_PRD.md#1`).

## 2. 통합 근거

원본 프로젝트가 없는 신설 제품이다(통합 대상 없음). 사용자 제공 자료(2026-11-11)의 BM 방법론과 PRD 초안에서 출발한다. 방법론은 제품이 아닌 공용 문서 `Price_Plans/_common/BM_METHOD.md`에 두고, 이 제품은 그 7단계를 Wizard·계산 엔진·스코어카드로 구현한다. 인증, 조직, 구독, 크레딧, 잡은 새로 만들지 않고 코어(`products/_platform-core/`)를 재사용한다. 확정 결정 인용: 결정 22(전 제품 공통 인증, `01_PRD.md#1` BM-F-001), 결정 4(결제는 코어 Toss 모듈, `02_ARCHITECTURE.md` 스택 표). 이 제품 자체를 다루는 확정 결정은 없다.

## 5. DB 구조 선택

도메인 테이블은 `bm` 스키마(번호 2700)에 두고 조직·구독·크레딧·잡·감사는 `core.*`를 참조만 한다(재정의 금지). 모든 테이블은 조직 소유 관계와 RLS를 갖는다(`01_PRD.md#9`). 모듈러 조각 파일명(제안: `2700_bm.sql`)과 모놀리스 포함 여부는 `05_DATA_MODEL.md` 9장에서 확정한다(팀장 결정 필요). 이유: 기본 구조는 다른 제품과 같게 두되, 계산 엔진은 DB와 무관한 TypeScript 패키지로 분리해야 하므로 엔진 경계를 먼저 정해야 한다.
