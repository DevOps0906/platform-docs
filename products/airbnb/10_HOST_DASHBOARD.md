# 10. Stay 호스트 대시보드 디자인

> 공용 대시보드 셸(사이드바 GNB + 탭 + 섹션 컴포넌트)에 Stay 디자인 시스템(08) 토큰을 적용한 디자인. 디자인 캔버스: "Stay 호스트 대시보드" (26 보드: 셸 1 + 화면 25).
> 화면의 숫자·이름·가격은 모두 **예시 데이터**다.

## 1. 구성 원칙
- 공용 셸 재사용: 사이드바 GNB, 접힘 상태, 모바일 홈/드로어, 탭, stats/table/list/split/steps/checklist/form 섹션.
- 토큰은 Stay DS(08)에서만 가져온다: surface #FAF7F2, accent #1F6F5C, highlight #B5541C(화면당 1곳), 상태색 success/warn/danger.
- 폰트: Pretendard는 Google Fonts에 없어 Noto Sans KR로 대체 (라이선스·배포 방식 미확인).

## 2. GNB 메뉴 → 화면
| GNB | 화면(탭) | 핵심 내용 |
|---|---|---|
| 홈 | 단일 | 오늘 할 일, 지표, 응답 대기 예약(승인/거절), 활동 피드, 주간 캘린더, 숙소 상태 |
| 예약 | 요청 / 다가오는 / 지난 / 취소 | 요청 분할 뷰, 응답 기한, 답변 폼, 정산 표 |
| 숙소 | 목록 / 등록 마법사(13단계) / AI 소개 초안 / 사진 | 상태 표, 13단계 진행, 제목 3안, 사진 체크 |
| 캘린더 | 월 보기 / 날짜 막기 / 차단 목록 | 월 그리드(체크인·요청·막음), 차단 폼 |
| 위키 | 문서 / 페이지 / 발행 점검 | 업로드·인제스트, 편집기, 린트 체크리스트 |
| 크레딧 | 잔액 / 사용 내역 / 단가표 / 플랜 | 잔액 요약, 사용 막대, 단가표 |
| 설정 | AI 처리 방식 / 알림 / 계정·팀 | 폼, 역할 표 |

## 3. 미확인·제안 값 (확정 아님)
- 크레딧 단가표·플랜(Free / Host Plus) 값은 01장 4.2의 **제안가**.
- info 색(#1F5F8B) 등 DS 보조 토큰은 제안.
- 실제 데이터 연동·권한(RLS)은 디자인 범위 밖. rls_smoke 재실행 안 함.
- 호스트 랜딩(`/host`)은 미설계.
