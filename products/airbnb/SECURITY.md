# Stay(airbnb) SECURITY

공통 규칙 정본은 `../_platform-core/SECURITY_BASELINE.md`(1~22장). 이 문서는 이 제품의 수치와 고유 위험만 적는다. 표기: "제안"은 근거 문서에 없어 이 문서가 정한 값, "미확인"은 확인 전. 상태: **1차 초안(2026-10-23)**

손님이 숙소를 예약하고 호스트가 숙소를 등록하는 플랫폼이라, 위험은 "정확한 주소 노출", "호스트 계정 탈취", "사기 유도", "공개 입구 남용"에 모인다.

## 1. 지켜야 할 자산

| 자산 | 종류 | 저장 위치 | 민감도 |
|---|---|---|---|

| 게스트 예약 정보(기간·인원·메시지) | 개인정보 | 예약 테이블 | 중간 |

| 호스트 사업자·영업신고 정보 | 개인정보/법 | 호스트 정보 설정 | 중간 |

## 5. 이 제품에만 있는 위험

- **숙박업 신고·통신판매중개:** 숙소 종류별 신고·등록과 중개자 고지 의무가 있어 플랫폼이 책임을 어디까지 지는지 법무 확인이 필요하다(01_PRD 6절).
- **위치:** MVP는 기기 GPS를 쓰지 않는다. "내 주변"을 넣으면 위치기반서비스 신고 대상 여부를 확인한다.
- **호스트 정보 검증:** 사업자·영업신고 번호는 입력값이므로 진위 확인 수단(공공 API 등)은 미결정.
